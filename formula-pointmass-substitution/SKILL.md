# 📐 经验公式质点代入法

**简称**：公式图（产物）／代入法（方法）
**技能 id**：`formula-pointmass-substitution`＝公式·质点·代入，与全称的三段结构一一对应

## 这张图是什么

一条（或一组）函数等式。它填的是**定量关系**：谁随谁怎么变、变化的量级是多少、这个系统与哪个已知系统同构。

产物不是一段推算，是**一个公式 + 它的适用边界**。

## 关系语法

只允许一种主边：

- **函数边** `Y = f(X₁, X₂, …)`：必须给出函数形式的出处与适用条件

其余所有潜在关系一律进入**被忽略清单**（负边），必须点名。

不允许"经验上大概""通常来说"这种无出处的系数——给不出出处，就必须标成假设。

## 四种动作

1. **切出实体**——抽象化，选出核心变量。变量清单不完整，公式就是错的方向。
2. **定语法**——选定公式或类比，写明出处与适用条件。
3. **质点化**——主动砍掉大部分自由度，只留一条主边。**砍掉的必须点名**：质点化是建模手段，不是忽略内部结构的许可。
4. **负边也是结论**——被忽略的自由度、假设被推翻的条件，都是结论的一部分。

## 代入前必须说明两件事

1. 被代入的经验公式／类比是什么（出处、适用条件）；
2. 质点模型的简化假设与边界在哪。

没说清这两条就代入，等于编数。

## 风险与对策（降维损失的账本）

1. **过度简化** → 每次迭代标注简化点（质点忽略了哪些自由度），收敛时检查假设是否被事实推翻。
2. **单位与量级漂移** → 每一步都带单位算；结论给量级 + 误差范围，不给假精度。
3. **公式错配** → 借用别的领域的公式前，先核对它的前提在本问题里是否成立。
4. **单点收敛** → 至少用两个独立估法交叉验证量级；只有一个公式时不宣称精度。

## 与其他两张图的关系

- 代入排在其他两张图之后：因果骨架与选项都没定之前不要建模。
- 建模前若核心概念边界模糊，先做定义前置。
- 复杂问题：林状图 → 网状图 → 公式图 联用，公式图负责最终收敛。
