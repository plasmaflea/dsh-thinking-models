# 🌳 林状分层分类回溯法

**简称**：林状图（产物）／回溯法（方法）
**技能 id**：`forest-hierarchical-backtracking`＝森林·分层·回溯

## 这一版的根：根落在「类」，不落在「个例」

回溯 = **不解决具体问题的宏观抽象化回溯**。所以：

- 根必然是面对**整个大类**的宏观内容，不是处理这一个具体问题的详细内容。
- 个例根（本次到底怎么了）必须挂在**类根**（这一大类在什么结构条件下才可能发生）下面，是子节点，不是平行清单。
- 因此每次回溯产出**两个根**：`处置根`（修本次）＋`消解根`（灭这一类）。
- 不算缺点的情况：本轮**不直接解决本次问题**——只要消解根把本次问题降级成更大问题的一个子项，并给出迁移清单。

## 0. 前置工作：先读知识树（每轮必做）

分类分层的知识树是**常量**，靠历史发展与反复核查养成；每轮回溯做的是**实例化与确认**，不是从零现编分类。

### 0.1 取树的四条路径，按序只取第一个**能读到**的

| 序 | 路径 | 说明 |
|---|---|---|
| ⓪ | `<常量库仓库>\knowledge-tree\index.md` | **真相源，存在则优先读它**。仓库名 `dsh-thinking-models-constants`，本机路径见 AGENTS.md 规则 15。不要拿工作区里的同名目录顶替——那份副本已按约定删除，留着就是第三个真相源 |
| ① | `<工作区>\knowledge-tree\index.md` | **工作区覆盖树。它不存在是正常情况，不构成「知识树不存在」**——直接进第 ② 条，不许因此宣布树缺失 |
| ② | `<技能目录>\tree\index.md` | **默认来源（常量库的生成副本，只读）**。`<技能目录>` 取 `skill` 工具输出里 `Base directory for this skill:` 的值，**用它拼路径，不要照抄任何示例中的绝对路径**。`tree/` 随技能一起安装（Skills Manager 按仓库清单逐文件落盘），所以第 ② 条在装好的机器上总该读得到 |
| ③ | 以上都读不到 | 降级为临时树 v0，并**必须在产物顶部第一行**写 `[⚠️ 知识树未加载：试过 <路径⓪> ／ <路径①> ／ <路径②>]` |

读索引之后**先判族、再找域**：族轴（恒等式族）决定 L2 走哪条轴，**不可缺**；域轴只给症状词与先例，**可缺**。判族只许按族表的判据，**不许按题面主题词**（「教育」「招聘」不是族名）。族命中而域未命中 ⇒ 直接用族，症状现描述并登记树外分支。

### 0.2 硬规则（这一条是为了修一次实测缺陷：5 个执行体里有 2 个加载失败并静默降级）

- 只读索引 → 按需读命中的节点文件，不要把整棵树灌进上下文。
- 读到树后，产物里必须回填**四元组**：`L1 树 = <节点> · v<N> · 核查 <日期> · 路径 <实际读到的文件路径>`。
  **没有「路径」这一项的 L1 行，视为未加载。** 写不出真实路径就不要写版本号。
- 静默降级比不读更糟：它会让结论看起来有树背书。读不到就挂牌，二选一。
- **过期要标**：核查日期超过一个季度，产物里写成「基于 vN，需复核」；不许把旧核查日当新核查日。
- 记录**本次判为不适用的节点**（这是判断，要留档）。
- 树里没有的分支 → 登记为「树外分支」进挂起表，**不许静默丢弃**；需要新节点时登记 `v(N+1) 候选` 并写理由。

树没有版本与核查日期 = 结论不可复核。缺节点不算错，静默使用才算错。

### 0.3 建树／校树：定义 → 分类 → 概念拆解（L0→L1 的入口）

树不是背出来的，是**造出来再传下去**的。这一节是造树（以及验树）的工序，位置在 L0 之后、L1 之前：L0 定类别，L1 取节点路径，中间那一步「这个类别是怎么被切开、又怎么被命名」就是本节。

**双档**：

- **快档（每轮默认）**：把题面关键词对回既有树的节点路径，口径没变就照用，一行带过。口径变了（同一个词在题面上的用法与树里节点的判据不一致）才停，转慢档。
- **慢档（造树）**：走完下面四步，产物登记为 `v(N+1) 候选` 进挂起表。慢档不每轮做，但**慢档的产物必须在树里留痕**——否则下次又退化成快档瞎猜。

**四步**：

| 步 | 动作 | 产物 | 合格判据 |
|---|---|---|---|
| ① 定义 | 给对象划界：内涵／外延／判定程序／边界情形 | 一句话定义 + 三条边界情形 | 能退化成判据（「算不算」问得出 yes/no） |
| ② 分类 | 按 §4 的轴切开，每格命名 | 一层格子 + 每格判据 | 过 §4 三判据：正交／可生成／可观测 |
| ③ 拆解 | 概念沿哪条边切开：属加种差／恒等式因子／时序阶段／边界情形 | 边清单 | 用至少两条不同的边切同一概念，结果必须同构 |
| ④ 登记 | 树里没有 → `v(N+1) 候选`；树里有但口径变了 → 改节点并升 `vN` | 挂起表一行 + 节点文件 | 写得出理由，写得出生效范围 |

**三条边界（这一节最容易越界的地方）**：

1. **定义只写事实，不写价值**。价值词（好／该／值得）不许进定义，只能作为 `G` 的持有者或明示判据出现——否则定义就不是定义，是把结论藏进名词里。
2. **描述性定义 ≠ 规定性定义**。描述性＝澄清既有用法（事实层，可中立）；规定性＝改判据（处置层，必须明示「我在改判据」，并说明旧判据下什么结论成立）。混用是偷换 `G` 的常见形态。
3. **分类必须补穷尽性**。§4 三判据只管「格与格不重叠、能生成、可观测」，不管「格加起来满不满」。补法不是硬凑格子，而是**兜底格**（「其余」）＋写明兜底里有什么。§4 的全空列判据是同一件事的另一半。

**触发条件**（不满足就别走慢档，避免每轮重新造树）：

- 题面出现「核心／本质／是什么／边界在哪／算不算／这算不算同一类」；
- 题面关键词对不上任何现有节点的判据；
- 同一个词在两次会话里被用来指两类东西。

**反模式**：

- 跳过定义直接建树 → 会在 L2 才发现格子对不上，回头重画；
- 用定义冒充结论 → 定义了，却没有 L2 的路径，定义变成修辞；
- 把「拆解」当穷举 → 拆解是切边（一个概念有哪几种切法），穷举是铺满（切完的格子里有什么）；产物不同，混用必漏。

**与 §4 的分工**：§4 管「怎么切」（生成式选轴），本节管「切开之后叫什么、凭什么这么叫」。轴错了全盘错，所以先验轴，再走本节。

## 1. 这张图是什么

一张有向无环的多根森林，填**纵向关系**：谁导致谁、谁是谁的必要或充分条件、谁与谁无关。产物不是一段推理，是一张关系图 + 一条上下级约定（个例根挂在类根下）。

## 2. 关系语法（先定语法，再填格子）

只允许两种边：

- **因果边** `A → B`：A 是 B 的必要条件或充分条件，必须标明是哪一种。标不出＝这条边是猜的。
- **挂起边** `A ⊥ B`：判定 A 不是 B 的根。必须写满四列——**分支 / 判定 / 依据 / 恢复条件**（在什么证据下这一行会被推翻）。

**禁止删除。删掉的枝不是没有根，只是被判为「不是根」——把有根的东西报成无根是虚假陈述。** 唯一合法的减少是**折叠**（父节点一行 + 子项清单），信息量不减、字符量减。

禁止跨维度边；不同维度只在**汇合层**合并，或各用一棵独立子树隔离——隔离靠结构，不靠自律。

## 3. 五层骨架（缺一层即不合格）

```
L0 类别判定   一行：类别 / 判据 / 已排除的大类
L1 树实例化   节点路径 · 版本 · 核查日期 · 本次判为不适用的节点
L2 类级回溯   层1 → 层2 → … → 类根 →（个例根挂在其下）
L3 双根       处置根（修本次） ／ 消解根（灭这一类，含不可发生判据）
L4 迁移出口   因消解根产生的新问题清单；本次问题降级为其中一项
```

**L0 允许一行完成。** 「不言自明也要写」不等于「要展开」——省略大类判定等于让后续全部回溯建在未声明的假设上（这正是倒推法走形 #1）。

## 4. 选轴（生成式，不是列举式）

轴必须由**必经过程**或**恒等式**机械生成，不得靠联想列举。每格必须写出「该格故障的可观测症状」。

三判据：**正交**（各格的根不互相解释对方的症状）、**可生成**（能一句话说出为什么这一步必然存在）、**可观测**（每格有专属症状）。

- **跳步规则**：链可以省（不必每一步都画），**格子不可省**（该出现的格必须有一行，哪怕写「此处无症状」）。
- **全空列判据**：所有格子都空而问题仍在 ⇒ 坐标系选错了，换轴重切，不是继续猜。
- **分支数由轴格数决定**：L2 的每一行必须标明它属于哪个轴格（`← 格N`）；写不出轴格的分支是联想，不是分支，只能进挂起表。这一条取代原来的「并行线 ≤ 3」——格数是可数的，≤3 是不可判的。同一父类超过 4 个轴格，先合并同源格：分解带不来新的独立性就是纯开销。

## 5. 分类与分层

- **分类三判据**见 §4（正交／可生成／可观测），此处不重复。没有判据列的「分类」是标签。
- 社会学问题：先按阶级／地位／身份／性别把涉及的人分类，再对事情本身分类。
- **分层判据**：按因-果联系、按必要／充分条件、按前置／后续关系。禁止按「重要性」或「易得性」分层。

## 6. 消解根的三条判据（写不出就降级为挂起）

1. **不可发生判据**：若当时采用这个条件，**本类问题在结构上不可能发生**。只是让它变少见 ＝ 缓解，不是消解。
2. **可执行首边**：必须给出「从现状到该状态的**第一条可执行边**」（可以很小，例如「先在 CI 里加一个容器跑测试」）。
3. **成本量级**：必须给出量级（联动 📐 结构图）。不给量级的换系统建议不可决策。

典型消解根长什么样：换掉产生这一整类的环境（如 Windows 服务形态 → Linux），或换掉让这类问题得以存在的结构（如「进程生命周期由 SCM 与加载器控制」→ 交还应用自身）。

### 6.1 消解根落在哪一层（不许跨层混说）

- **类根、因果链 → 事实层**：可中立、可验证，不必锁 `G`。
- **处置根、消解根 → 处置层**：必然锁一个 `G`（＝类的所有者），换 `G` 就是换题。
- 消解只有两解：①**重定义边界**（事实层，原题仍成立）②**改 `G`／灭一整类**（处置层，须**明示** `[已换题：新问题 = …，原问题未解]`，并过 §6 三道闸门）。
- 判据一问：**改完之后，原先问的那句话还成立吗？** 成立是①，不成立是②。
- 三问检测器：原话还成立吗／成功判据变了吗／责任主体或时间尺度变了吗。
- **明示**＝写下来、可被外部检查；不写即**默示**——对持有者有效、对外部不可审计，是最坏形态。
- 定义只能消解**定义病**（各方说的不是同一件事／伪问题），不能消解**约束病**（配额／资源／不可逆）。判据：澄清后约束还在不在。

## 7. L4 迁移出口（这是「头疼医人」的合法性来源）

消解根一旦指向环境/架构变更，本轮**必须**列出迁移问题清单，并写明本次问题降级为其中一项：

- 数据与状态（存储迁移、格式转换、一致性校验）
- 运行与自启（服务管理器语义差异）
- 可观测性（日志/指标/转储的落点变化）
- 凭据与权限模型
- 组织能力（运维技能、值班流程）

没有 L4，「不解决具体问题」就是遗漏，不是策略。

## 8. 排序是预算的函数

候选根按 `Share × Lever ÷ Cost` 排序，取前 N 条去验证，其余留在挂起：

| 列 | 含义 | 取值 |
|---|---|---|
| **份额 Share** | 能解释已观测现象的比例 | 唯一／主因／共因／次要／无 |
| **可控性 Lever** | 能不能动它 | 改配置／改架构／换环境／动不了 |
| **证伪代价 Cost** | 排除它要花多少 | 一次采样／一次重启／一次迁移 |

**Cost 就是预算。预算无限 ⇒ Cost→0 ⇒ 排序失效 ⇒ 产物退化成清单而不是答案。** 所以限制不是精度损失源，排序必须带预算。

候选根表必须是**上下级结构**：类根在上，个例根在下，不许平铺成一张长表。

## 9. 与其他两张图的关系

未知在**因果深度** → 林状图；未知在**选项广度** → 网状图；未知在**数量关系** → 结构图。
复杂问题按 林状图 → 网状图 → 结构图 联用：先定因果骨架，再穷举选项，最后定量收敛。
消解根的成本量级、迁移清单的工作量，必须交给结构图定量——**不在林状图里凭空给数字**。

## 10. 交付闸门（六问，逐条 yes/no）

规则再多，交付前不逐条过就等于没写。六问全 yes 才许交付；任一是 no，回去改，不许在正文里加免责声明糊过去。

| # | 问 | no 时改哪里 |
|---|---|---|
| 1 | 冻结句逐字抄在产物最上方（模式标识之下第一行）了吗？ | §11-1 |
| 2 | 每个 L2 行都写了**轴格**与**题面锚点**（冻结句的原文片段）吗？ | §4 / §11 |
| 3 | L1 四元组里有**真实读到的文件路径**吗？ | §0.2 |
| 4 | 每个候选根都标了 `发生／维持／杠杆／归责` 之一吗？ | §12-1 |
| 5 | 挂起表每行都写了**恢复条件**（不是「暂不考虑」）吗？ | §2 |
| 6 | 结论第一句**直接回答冻结句**，且没混进方案吗？ | §11-3 |

原 §10 的七条风险没有丢，各自并进了可判定条款：树变剪枝借口→§0.2（树外分支登记）；大类空转→§6（可执行首边＋成本量级）；常量树腐烂→§0.2（版本＋核查日＋过期标记）；忽略旁支→§2（挂起表）；单根树跨维度→§2（独立子树隔离）；分支爆炸→§4（分支数＝轴格数）；全空列→§4。

## 11. 重点保全（三句 + 两个必填字段）

> 这一节来自一次实测：同一个执行体、同一份技能，在分支最多的两轮里漏条款最多（没写症状、没写类根、没标换题），在收敛成一主轴的轮次里条款执行最全。**结论不是「要更自律」，是「换成可判定的问句」。**

规则不缺，缺的是能当场答 yes/no 的话。三句，按顺序用：

| # | 机制 | 一句话形态 | 挡住什么 |
|---|---|---|---|
| 1 | **题面冻结** | 把提问者原话**逐字**抄在产物最上方（模式标识之下），全程不改写；任何「重点」必须能从这句话里读出来 | 把原话**翻译**成任务时重点被换掉（实测：问「为什么」被译成「找根因并给方案」） |
| 2 | **删掉检验** | 删掉这段推理，**结论是否改变**？不变→干扰（挂起）／变弱→支撑（可降级为脚注）／不成立→必要 | 无关分支。这是 §5「按必要／充分条件分层」的机械化形态 |
| 2b | **删掉检验的补丁** | 再问一句：删掉它，会不会让某个**错**的结论变得可信？会 → 保留（预防性） | 预防性论据被误删 |
| 3 | **类型分叉** | 问「为什么」⇒ 结论第一句必须是冻结句的直接回答；处置根与 L4 必须带「以下是推论，不是你所问」标记，方案不许写进结论第一句 | 五层骨架的 L3/L4 是必填层 ⇒ 问「为什么」也会长成「改制度」 |

**两个必填字段（替代原来的第 3、5 条）**：

| 字段 | 填法 | 取代了什么 |
|---|---|---|
| **轴格** | 每个 L2 行尾写 `← 格N` | 「并行线 ≤ 3」——格数由 §4 生成，可数；≤3 没有校验器 |
| **题面锚点** | 每个 L2 行尾写 `锚「片段」`，片段必须是冻结句里逐字存在的几个字 | 「每三支回读」——逐行可查；「每三支」这个时点在单次作答里根本不会触发 |

两个字段都填不出的分支 ⇒ 进挂起表（判为联想）。**这就是把不可判的计数与时点，换成可判的字段。** 条款若有校验器就留，没有就换成字段——字段不靠自律。

**锚点的防伪与退化**（否则字段会被主词糊过去）：①片段必须**带谓词**，只抄主词不算（`教育制度`／`问题` 不是锚）；②同一片段最多复用 2 行——能一字不改地复用到处，说明它没在区分任何东西；③**短题面允许退化**：谓词片段比 L2 行数少时，该行写 `锚∅` 并注明「题面只有一句 × 字，锚点检查退化为闸门第 6 问」。**退化要挂牌，不许拿主词凑数。**

**为什么「删掉检验」比「这重要吗」有效**：后者不可判（没有判据，只能凭感觉）；前者可判（跑一遍，看结论变不变）。**把不可判的问题换成可判的问题，就是这一节的全部作用。**

**顺序警告**：先发散、再删。反过来（先收敛再补）补不回来——实测过一次：早期只留「系统稳定」一条线，丢掉「数量」这个变量，后面四轮都在补它。

## 12. 标注义务（漏一条即不合格）

1. **根的类型**：每个候选根必须标 `发生`／`维持`／`杠杆`／`归责`（定义见知识树索引「根四型」）。不标 ⇒「中段能不能当根」的争论无解。
2. **可选集**：凡涉及「参与者」的题，必须给出每类人的**可选集大小与来源**：`有效竞争`（可选项 ≥2 且自选）／`被迫竞争`（可选项 =1，其余选项低于生存线）／`被裹挟`（本可 ≥2，被信息、资格或时点排除）。
   **理由**：这些是**分区属性**，不是标量。把「被迫」压进「总量／强度／权重」这类标量，会把它投影掉，而且**投影不可逆**。
3. **分类是约束，不是入口**：L0 判一次就全量沿用＝把分区属性碾平。每层量化前必须重新分区。代价是多一次判类；漏掉的代价是整条结论只对某一层成立，却被当成对全体的结论。
