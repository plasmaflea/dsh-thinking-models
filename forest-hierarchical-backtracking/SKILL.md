# 🌳 林状分层分类回溯法

**简称**：林状图（产物）／回溯法（方法）
**技能 id**：`forest-hierarchical-backtracking`＝森林·分层·回溯，与全称的三段结构一一对应

## 这张图是什么

一张有向无环的因果图——多根森林。它填的是**纵向关系**：谁导致谁、谁是谁的必要或充分条件、谁与谁无关。

产物不是一段推理，是一张**关系图**。

## 关系语法（先定语法，再填格子）

只允许两种边：

- **因果边** `A → B`：A 是 B 的必要条件或充分条件，必须标明是哪一种；标不出，说明这条边是猜的
- **无关边** `A ⊥ B`：断言两者无因果关系，必须附剪枝理由

禁止跨维度边。不同维度只在**汇合层**合并。

## 四种动作

1. **切出实体**——按正交维度出分支，每维一棵独立子树。维度必须互不重叠，重叠必然导致跨维度跳跃。
2. **定语法**——逐边判定「必要／充分／无关」，不允许含糊的「相关」。
3. **配对完整**——每个节点必须完整分叉到**所有**维度。没分叉的维度＝漏掉的根。
4. **负边也是结论**——结尾必须报「被排除分支＋剪枝理由」。说「X 与此无关」和说「X 是根」同等重要。

## 回溯根源：三层缺一不可

回溯根源 ＝ 「问题产生的背景或现象」＋「提问者想解决自己的什么现象」＋「问题本身的根源」。

其他两层可以在逻辑通顺的情况下被其中一层覆盖或包含，从而得到真正的"根源"。多维度时各自独立回溯到根，再由汇合层合并。

## 分类与分层的取法

- 社会学问题：先按阶级／地位／身份／性别等把涉及的人分类，再对事情本身分类。
- 分层方式：按因-果联系、按必要／充分条件、按前置／后续关系分层。

## 风险与对策（降维损失的账本）

1. **易忽略旁支路径** → 回溯前先枚举所有父类分支，再逐个剪枝，结尾报告被排除的分支。
2. **单根树易跨维度跳跃** → 用独立子树在结构上隔离不同维度，不靠自律。
3. **分支爆炸** → 严格沿因果链分类，不随意扩展维度。
4. **过度分解** → 维度超过 4 个先合并同源维度；分解带不来新的独立性就是纯开销。

## 与其他两张图的关系

未知在**因果深度**→林状图；未知在**选项广度**→网状图；未知在**数量关系**→公式图。
复杂问题按 林状图 → 网状图 → 公式图 联用：先定因果骨架，再穷举选项，最后定量收敛。
