# 🌳 林状分层分类回溯法

**简称**：林状图（产物）／回溯法（方法）
**技能 id**：`forest-hierarchical-backtracking`＝森林·分层·回溯

## 这一版的根：根落在「类」，不落在「个例」

回溯 = **不解决具体问题的宏观抽象化回溯**。所以：

- 根必然是面对**整个大类**的宏观内容，不是处理这一个具体问题的详细内容。
- 个例根（本次到底怎么了）必须挂在**类根**（这一大类在什么结构条件下才可能发生）下面，是子节点，不是平行清单。
- 因此每次回溯产出**两个根**：`处置根`（修本次）＋`消解根`（灭这一类）。
- 不算缺点的情况：本轮**不直接解决本次问题**——只要消解根把本次问题降级成更大问题的一个子项，并给出迁移清单。

## 0. 前置工作：先读知识树（每轮必做）

分类分层的知识树是**常量**，靠历史发展与反复核查养成；每轮回溯做的是**实例化与确认**，不是从零现编分类。

### 0.2 硬规则（这一条是为了修一次实测缺陷：5 个执行体里有 2 个加载失败并静默降级）

  **没有「路径」这一项的 L1 行，视为未加载。** 写不出真实路径就不要写版本号。

## 1. 这张图是什么

一张有向无环的多根森林，填**纵向关系**：谁导致谁、谁是谁的必要或充分条件、谁与谁无关。产物不是一段推理，是一张关系图 + 一条上下级约定（个例根挂在类根下）。

## 2. 关系语法（先定语法，再填格子）

只允许两种边：

- **因果边** `A → B`：A 是 B 的必要条件或充分条件，必须标明是哪一种。标不出＝这条边是猜的。
- **挂起边** `A ⊥ B`：判定 A 不是 B 的根。必须写满四列——**分支 / 判定 / 依据 / 恢复条件**（在什么证据下这一行会被推翻）。

**禁止删除。删掉的枝不是没有根，只是被判为「不是根」——把有根的东西报成无根是虚假陈述。** 唯一合法的减少是**折叠**（父节点一行 + 子项清单），信息量不减、字符量减。

禁止跨维度边；不同维度只在**汇合层**合并。

## 3. 五层骨架（缺一层即不合格）

```
L0 类别判定   一行：类别 / 判据 / 已排除的大类
L1 树实例化   节点路径 · 版本 · 核查日期 · 本次判为不适用的节点
L2 类级回溯   层1 → 层2 → … → 类根 →（个例根挂在其下）
L3 双根       处置根（修本次） ／ 消解根（灭这一类，含不可发生判据）
L4 迁移出口   因消解根产生的新问题清单；本次问题降级为其中一项
```

**L0 允许一行完成。** 「不言自明也要写」不等于「要展开」——省略大类判定等于让后续全部回溯建在未声明的假设上（这正是倒推法走形 #1）。

## 4. 选轴（生成式，不是列举式）

轴必须由**必经过程**或**恒等式**机械生成，不得靠联想列举。每格必须写出「该格故障的可观测症状」。

三判据：**正交**（各格的根不互相解释对方的症状）、**可生成**（能一句话说出为什么这一步必然存在）、**可观测**（每格有专属症状）。

- **跳步规则**：链可以省（不必每一步都画），**格子不可省**（该出现的格必须有一行，哪怕写「此处无症状」）。
- **全空列判据**：所有格子都空而问题仍在 ⇒ 坐标系选错了，换轴重切，不是继续猜。

## 5. 分类与分层

- **分类三判据**：正交（互不重叠）、可生成（有判定程序，不是命名）、可观测（每类有区分性症状）。没有判据列的「分类」是标签。
- 社会学问题：先按阶级／地位／身份／性别把涉及的人分类，再对事情本身分类。
- **分层判据**：按因-果联系、按必要／充分条件、按前置／后续关系。禁止按「重要性」或「易得性」分层。

## 6. 消解根的三条判据（写不出就降级为挂起）

1. **不可发生判据**：若当时采用这个条件，**本类问题在结构上不可能发生**。只是让它变少见 ＝ 缓解，不是消解。
2. **可执行首边**：必须给出「从现状到该状态的**第一条可执行边**」（可以很小，例如「先在 CI 里加一个容器跑测试」）。
3. **成本量级**：必须给出量级（联动 📐 结构图）。不给量级的换系统建议不可决策。

典型消解根长什么样：换掉产生这一整类的环境（如 Windows 服务形态 → Linux），或换掉让这类问题得以存在的结构（如「进程生命周期由 SCM 与加载器控制」→ 交还应用自身）。

### 6.1 消解根落在哪一层（不许跨层混说）

- **类根、因果链 → 事实层**：可中立、可验证，不必锁 `G`。
- **处置根、消解根 → 处置层**：必然锁一个 `G`（＝类的所有者），换 `G` 就是换题。
- 消解只有两解：①**重定义边界**（事实层，原题仍成立）②**改 `G`／灭一整类**（处置层，须**明示** `[已换题：新问题 = …，原问题未解]`，并过 §6 三道闸门）。
- 判据一问：**改完之后，原先问的那句话还成立吗？** 成立是①，不成立是②。
- 三问检测器：原话还成立吗／成功判据变了吗／责任主体或时间尺度变了吗。
- **明示**＝写下来、可被外部检查；不写即**默示**——对持有者有效、对外部不可审计，是最坏形态。
- 定义只能消解**定义病**（各方说的不是同一件事／伪问题），不能消解**约束病**（配额／资源／不可逆）。判据：澄清后约束还在不在。

## 7. L4 迁移出口（这是「头疼医人」的合法性来源）

消解根一旦指向环境/架构变更，本轮**必须**列出迁移问题清单，并写明本次问题降级为其中一项：

- 数据与状态（存储迁移、格式转换、一致性校验）
- 运行与自启（服务管理器语义差异）
- 可观测性（日志/指标/转储的落点变化）
- 凭据与权限模型
- 组织能力（运维技能、值班流程）

没有 L4，「不解决具体问题」就是遗漏，不是策略。

## 8. 排序是预算的函数

候选根按 `Share × Lever ÷ Cost` 排序，取前 N 条去验证，其余留在挂起：

| 列 | 含义 | 取值 |
|---|---|---|
| **份额 Share** | 能解释已观测现象的比例 | 唯一／主因／共因／次要／无 |
| **可控性 Lever** | 能不能动它 | 改配置／改架构／换环境／动不了 |
| **证伪代价 Cost** | 排除它要花多少 | 一次采样／一次重启／一次迁移 |

**Cost 就是预算。预算无限 ⇒ Cost→0 ⇒ 排序失效 ⇒ 产物退化成清单而不是答案。** 所以限制不是精度损失源，排序必须带预算。

候选根表必须是**上下级结构**：类根在上，个例根在下，不许平铺成一张长表。

## 9. 与其他两张图的关系

未知在**因果深度** → 林状图；未知在**选项广度** → 网状图；未知在**数量关系** → 结构图。
复杂问题按 林状图 → 网状图 → 结构图 联用：先定因果骨架，再穷举选项，最后定量收敛。
消解根的成本量级、迁移清单的工作量，必须交给结构图定量——**不在林状图里凭空给数字**。

## 10. 风险与对策（闸门清单）

1. **知识树变成剪枝借口**（「树里没这一支，所以不考虑」）→ 树外分支必须登记进挂起表。
2. **大类空转**（每层往上走，最后所有问题都变成「换个更好的系统」，结论不可执行）→ 消解可行性闸门：可执行首边 + 成本量级，缺一降级。
3. **常量树腐烂** → 版本 + 核查日期必须出现在产物里，过期要标「基于 vN，需复核」。
4. **忽略旁支** → 先枚举父类分支再逐个挂起，结尾报挂起表。
5. **单根树跨维度跳跃** → 用独立子树在结构上隔离维度，不靠自律。
6. **分支爆炸／过度分解** → 同一父类超过 4 个维度先合并同源维度；分解带不来新的独立性就是纯开销。
7. **全空列**（所有格子都空）→ 坐标系错误，换轴重切。
