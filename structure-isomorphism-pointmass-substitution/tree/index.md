## 0. 开题（三步：锁 G → 检索先例 → 定结构）

### 0.0 G 锁定与明示（最先）

**立场 = `G` 槽 = 设计目的。** 换立场不是换说法，是换成功判据——也就是换题。

| 判据 | 结论 | 怎么处理 |
|---|---|---|
| 两方对「怎样算解决」**一致**，只是对事实判断不同 | **事实分歧** | 取证能解，别用立场解释 |
| 两方对「怎样算解决」**不一致** | **立场分歧** | 证据解决不了。**一次只解一个 `G`**，其余并列登记，**不做裁决** |

**冻结 ≠ 忽略。** 「不考虑设计目的」的正确操作是把 `G` 当**已知输入固定住、不再讨论它该不该改**；不是假装它不存在。
假装不存在 = 静默继承一个未声明的 `G`，这是最糟的情况（**不可审计**）。所以每个产物先**明示** `G`——**明示**＝写下来、可被外部检查；不写即**默示**，默示 `G` 对持有者有效、对外部不可审计：

```
[G 明示] 采用 G = <...> · 持有者 = <...> · 成功判据 = <...> · 其余立场已登记于立场表
```

**立场表（并列不裁决）**：`G / 持有者 / 若采用则问题长什么样 / 本作答是否采用`。
不同 `G` 的方案若结构性冲突（一方要你犹豫、一方要你清醒），那是**目标函数冲突**，不是道德问题——如实列出，不调和。

**难 vs 不可达（决定结构图管不管）**：
- 给定 `G` 与约束 `C`，从 `S` 到 `G` 的**路径集非空、只是代价高** → 「**难**」→ 结构图解。
- **路径集为空** → 「**不可达**」→ 这是 **spec bug，不是实现 bug** → 回 🌳 林状图做 spec 评审，结构图**不处理**。
- 常见伪装：「这问题太难了／无解」。判据只有一条——**能不能举出一条可行路径**。举不出却声称无解，是在评价 spec，不是在解问题。

### 0.1 先例检索（强制，缺一不算作答）

紧接锁 G 之后，代入法要回答的不是「这是什么结构」，而是「有没有已经解决的高度相似问题」。顺序不能颠倒：先例给的是**已验证的解法**，结构给的是**为什么那个解法能用**。

| 级 | 判据 | 命中后怎么用 | 产物标签 |
|---|---|---|---|
| **T1 高相似** | 变量集 ↔、边型 ↔、边界大部分包含；**且该问题已被解决、解法可复述** | **直接迁移解法**，只校验边界差异；参数不得照搬 | `[T1 先例：<问题> → <解法>]` |
| **T2 低相似** | 边型对得上，但变量集或边界差一项以上 | 只迁移**处置顺序**，不迁移参数与量级 | `[T2 类比，非同一结构]` |
| **T3 无先例** | 两轮检索都空 | **新造结构**：现填八槽 → 定机制 → 命名 → 入库为候选；写明「新造，未经先例验证」 | `[T3 新造：<结构名>]` |

**T1 的第四校验：`G` 同向性**。除变量集 ↔、边型 ↔、边界包含之外，还须校验「**先例的执行者**」与「**本次的问题主体**」目标是否同向。
- 同向 → 解法可直接迁移（例：省考试院的目标 = 公平录取，与考生同向，故平行志愿可搬）。
- 反向 → 只可迁移**不依赖执行者的部分**（自查、自建回路），**不可迁移由该执行者提供的服务**（例：按成交收费的中介与求偶者不同向，故其「方案」必然偏离）。

**强制输出三行之一**（写在产物最前）：

```
[T1 命中]  高相似已解决：<问题> —— 解法：<...> —— 可迁移：<...> —— 不可迁移：<...>
[T2 命中]  无高相似；低相似：<问题> —— 只借处置顺序：<...>
[T3 无先例] T1/T2 均空 —— 新造 <结构名>：八槽 = ... —— 已登记 v3 候选
```

> **跳过这三行 = 没有作答**，等于凭记忆现编。

**检索源（按序）**：①本索引 §6 复合表 + §7 各基的 `已解决先例` 字段 → ②12 个基节点文件的 `已知同构问题` → ③库外常识（须标注「库外先例，未入库」）。
**T1 允许跨域**：先例不必同领域，只看变量集与边型——高考志愿之于婚配市场，就是跨域 T1。

### 0.2 结构图内禁止消解

- **消解 = 改 `G` 槽或改边界 = 换了题**，不是解题。
- 结构图的职责是**解决具体问题**，产物必须落到具体动作；「重新定义边界让问题消失」是 🌳 林状图的动作，搬进结构图即**越界**。
- **三问检测器**（任一为「是」即判为换题）：①用户最初问的那句话，消解后还成立吗？②成功判据变了吗？③责任主体或时间尺度变了吗？
- 换题不禁止，但**必须明示**：`[已换题：新问题 = <...>，原问题未解]`，然后**回到原问题继续作答**。
- **配额决定的不可解部分不得试图消解**（如「不可能所有人同时向上移动」）——它解不了。可解的是**错配浪费**（滑档、高分低就、临门一脚错过）。把两者混成一个问题再「消解」，必然换题。
- **消解二分解（v2.3 裁决）**：①**重定义边界**＝事实层动作，任意模式合法（只改边界不改 `G`，原题仍成立）；②**改 `G` 或灭一整类**＝处置层动作，须**明示** `[已换题]` 并过 🌳 三道闸门。**结构图只许①**。判别只需一问：「改完之后，原先问的那句话还成立吗？」——成立是①，不成立是②。
- **`G` 可见度分级**（决定「要不要每次锁」）：**已内嵌**（法律／合同／工程规范）→ 不必每次锁，须标出处；**已公开**（对方声明过）→ 引用并标「按你声明的 `G`」；**未声明** → 必须锁 + 明示。故「技术问题不必看立场」的真相是**该领域 `G` 内嵌度高**，不是立场缺席。

## 1. 统一骨架（一切问题拆成同一个 8 元组）

| # | 槽 | 填什么 | 为什么这一槽必然存在 |
|---|---|---|---|
| 1 | **E 实体集** | 有策略的主体 ┊ 无策略的对象 | 决定边是「函数」还是「互定」 |
| 2 | **S 状态** | 被数的量（存量／水平／当前选项） | 无状态即无问题 |
| 3 | **F 流** | 进／出／转换（速率） | 状态只能经流改变 |
| 4 | **C 约束** | 硬上限（预算／容量／规则／时间） | 无约束则偏差可无限修正 |
| 5 | **G 目标** | 给定 ┊ 待定 ┊ 不存在 | 决定问题形态（§2） |
| 6 | **M 维持** | 偏差为何不自愈（§2 九选一或组合） | **分类轴**：这是本库唯一的分区依据 |
| 7 | **O 观测** | 度量 + 噪声 + 隐藏 | 所有槽只能被观测；无观测即无判断 |
| 8 | **A 杠杆** | 能改哪个槽 | 处置动作的生成器（§5） |

**边型** = `F → S` 的积分关系：乘 / 加 / 守恒 / 幂 / 饱和 / 不连续 / 互定 / 概率合成 / 无闭式。
**边界** = 哪些槽被视为**外生**（本次不追究）。边界不是脚注，是结构的一部分。

**两类填充**：`G` 给定 → 偏差型（问「怎么补上」）；`G` 待定/不存在 → 决策型（问「选哪个／造什么」）。

## 2. 事件分类（生成轴，不列举）

分类轴＝恒等式 **`问题 = 目标状态 × 维持机制`**。

**轴一 · 目标状态**（`G` 槽的三种填充，互斥且可观测）

| 形态 | 判据 | 要问的 |
|---|---|---|
| **差距型** | 目标已知，现状可测，有差距 | 怎么补上 |
| **取舍型** | 目标之间要权衡，选项已存在 | 选哪个 |
| **创造型** | 目标或选项还不存在 | 造什么 |

**轴二 · 维持机制**（这一个问题就够了：**「这个偏差为什么不会自己消失？」**）

| 答案 | 族 | 基 | 判据 |
|---|---|---|---|
| 因为没有回复力 | **流** | `multiplicative-rate`、`conservation` | 进出不等，且没有力把它推回去 |
| 因为有回复力但被顶住 | **限** | `additive-budget`、`queue-capacity`、`saturation` | 有上限，逼近时成本非线性 |
| 因为回复力随规模变差 | **量级** | `power-scale` | 规模 `n` 一变，单位成本就变 |
| 因为有回路把它放大 | **环** | `feedback-loop` | 输出回到输入，增益 `g` 决定爆不爆 |
| 因为要越过临界点才回复 | **闸** | `threshold-switch` | 看起来正常，然后突然不行 |
| 因为有人靠它获利 | **弈** | `adversarial-game` | 一方的行动取决于对另一方的预判 |
| 因为没人看得见 | **信** | `signal-inference` | 真值不可观测，且有人在选择发什么 |
| 因为环节多，断一环就全断 | **链** | `series-reliability` | 存活率连乘，最弱环决定整体 |
| 因为地形多峰，看不到更好的 | **搜** | `search-landscape` | 卡在局部最优，且跳峰要先下坡 |

> 这个轴为什么是**生成**的而不是**列举**的：偏差若能自愈，它就不成其为问题。所以「维持机制」必然存在；
> 而让偏差持续的方式只有「无力回收（流）／回收被顶住（限）／回收随规模失效（量级）／反向放大（环）／
> 回收有断点（闸）／有人维持（弈）／无人知道（信）／任一环断（链）／看不见别处（搜）」，**穷尽**。
> 九行之外若真有答案，才是真正的 v3 候选。

## 3. 基表（12 = 量的六 + 质的六）

### 量的六（v1 原样）

| id | 名称 | 边型 | 一句话判据 | 越界退化成 | 节点文件 |
|---|---|---|---|---|---|
| `multiplicative-rate` | 乘性速率分解 | `T = N·∏αᵢ` | 总量能拆成互相独立、可连乘的因子 | 因子相关→条件函数；饱和→`saturation` | `multiplicative-rate.md` |
| `conservation` | 守恒／账本 | `ΔS = 流入 − 流出` | 边界清晰，进出可记账 | 有未记账旁路→先补账 | `conservation.md` |
| `saturation` | 饱和／非线性 | `W ∝ S/(1−ρ)` | 有利用率 ρ，ρ→1 成本发散 | 突发→只给量级；ρ≥1→不收敛 | `saturation.md` |
| `power-scale` | 幂律／规模效应 | `Y = k·n^b` | 规模变则单位成本变 | 跨机制→分段；n<3→逐个估 | `power-scale.md` |
| `additive-budget` | 加性预算 | `Σhᵢ ≤ B` | 串联路径，总预算被各段消耗 | 并行→`max`；重试→乘性叠加 | `additive-budget.md` |
| `queue-capacity` | 排队-容量 | `L=λW`；`吞吐=min(λ,C/S)` | 有排队、有并发上限、有服务时间 | 超时丢弃→只给上界 | `queue-capacity.md` |

### 质的六（v2 新增，节点在本目录）

| id | 名称 | 边型 | 一句话判据 | 越界退化成 | 节点文件 |
|---|---|---|---|---|---|
| `feedback-loop` | 反馈环 | `X_{t+1}=g·X_t+外生` | 能指出「输出→输入」的路径，且 `g>1` 会发散 | 饱和→S 型；有主体→`adversarial-game` | `feedback-loop.md` |
| `threshold-switch` | 阈值切换 | 分段常数／分段幂律，`x*` 处不连续 | 看起来正常，然后突然不行 | 有滞回→必须给 `x**_r`；级联→叠环 | `threshold-switch.md` |
| `adversarial-game` | 对抗博弈 | **互定**：`uᵢ = fᵢ(sᵢ, s₋ᵢ)` | 一方行动取决于对另一方的预判 | 一方无策略→退回机制类 | `adversarial-game.md` |
| `signal-inference` | 信号推断 | 信息通道：`I(y;θ) < H(θ)` | 真值不可观测，且信号被**选择**发送 | 无噪声结构→只给方向 | `signal-inference.md` |
| `series-reliability` | 串联可靠性 | `R = ∏ rᵢ`（并联 `1−∏(1−rᵢ)`） | 多环节，任一断则全断 | 失效相关→只给上界 | `series-reliability.md` |
| `search-landscape` | 搜索地形 | 无闭式；局部最优 + 探索成本 | 卡在局部最优，跳峰要先下坡 | 评估不可靠→叠抽样误差 | `search-landscape.md` |

### 节点必备字段（缺一不算节点）

`模式 id / 变量集 / 边型 / 边界条件 / 已知同构问题 / **已解决先例（问题 + 解法 + 不可迁移段）** / 典型处置动作 / 越界退化成什么 / 反例`

> `已知同构问题` 用于**识别**（这问题像哪一类）；`已解决先例` 用于**迁移**（哪一类已经被解决、怎么解的）。
> 两者不是一个字段：前者证明「像」，后者证明「能解」。v1 把两者混成一个，是 v2.1 补的第二处漏洞。
> **注意**：6 个 v1 节点尚未补 `已解决先例`。用前先问一句「这个结构在哪个领域被真正解决过」；问不出 → 降级 `[类比]`，只给量级。

## 4. 修饰符（2，作用于任意基，不单独成类）

| id | 名称 | 加什么 | 何时必须挂 |

|---|---|---|---|
| `sampling-error` | 抽样误差 | 观测 = 真值 + 噪声；`n` 小 → 假精度 | **任何要给数字的结论**。给点估计而不给区间，就是它 |
| `irreversibility` | 不可逆 | 错了不能撤 → 期权价值、沉没成本、承诺的威慑力 | 决策不可撤回、或撤回代价 ≥ 收益时 |

## 5. 组合规则（3 条，基变复合的唯一方式）

| 规则 | 形状 | 处置含义 |
|---|---|---|
| **叠加 ⊗** | 两个机制同时作用于同一偏差（内卷＝弈⊗环） | 必须**同时**动两个；只动一个会被另一个抵消 |
| **串联 →** | 一个的输出是另一个的输入（积压→丢弃→观测失真） | 处置**必须从上游开始**；下游修复会被上游重新击穿 |
| **嵌套 ⊂** | 一个机制在更大机制内部（团队内博弈 ⊂ 公司间博弈） | 先判**哪一层是约束层**；改内层不改外层等于白改 |

## 7. 命名复合表（世界上的「常见问题」多半落在这里）

## 8. 识别协议（七步：锁 G → 先例 → 结构 → 落地）

0. **锁 G**（§0.0）：明示 `G`／持有者／成功判据；剥不出 → 定义前置，退回。同时判「**难 vs 不可达**」：路径集为空即 **spec bug**，回 🌳 林状图，结构图不接。
1. **先例检索**（§0.1）：T1 → 迁移解法并做四项校验（变量集／边型／边界／**G 同向性**）；无 T1 → T2 → 只借处置顺序；都无 → T3 新造并登记。**此步没出结论，不得进入第 2 步**。
2. **填 8 槽**（§1）。填不满 → 缺的是信息，不是结构，先去取证。
3. **问一句**：「这个偏差为什么不会自己消失？」→ 对到 §2 九行之一；命中多个 → §5 定「叠加／串联／嵌套」。
4. **查复合**（§7）：若已是命名复合，直接取其组成基，不必重新推理。
5. **边界校验 + 质点化**（技能原有动作不变）：变量集齐否／边型对否／本问题取值落在边界内否；砍掉的自由度是不是另一个基的核心自由度。
6. **落地**：产物必须收敛到**具体动作**——谁、什么时点、做什么、成本多大。停在「原则」「方向」「消解」都不算交付（§0.2）。

**基未命中协议**（先例够 T1，但基表里没有对应结构）：
1. 先查 §7 复合，再查 §5 两种基的组合；
2. 仍无 → 登记 **v3 候选**（写：问题、九行都不命中的理由、试过的组合）；
3. 同时**当场给类比**，显式标 `[类比，非同一结构]`，**只给量级区间，不给方案**；
4. 每季度归并一次候选，**不许把候选直接塞进基表**（那是目录化，会把库撑爆）。

## 9. 本库的边界（不处理什么）

- **目标不存在且不可定义** → 定义前置问题，不是结构图。先定义「好」是什么。
- **价值不可公度**（伦理／审美／两种好无法比较）→ 只能标「不可公度」，不给量级、不给排序。
- **纯历史叙事**（无重复机制的一次性事件）→ 结构图无效，只能类比，必须挂牌。
- **同构只迁移「问题类型与处置顺序」，不迁移数字**。参数迁移必致假精度。
