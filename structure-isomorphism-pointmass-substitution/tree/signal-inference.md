# 信号推断（`signal-inference`）

**边型**：**信息通道**，不是加减乘：`I(观测; 真值) < H(真值)`。
`观测 = 真值 ⊕ 噪声 ⊕ 隐藏`；且**信号由行动者选择**（策略性发送）。

**变量集**
- `θ`：真值/类型（能力、质量、健康状况、意图）
- `y`：观测（简历、评分、体检报告、财报）
- `ε`：噪声（方差、灵敏度/特异度）
- `c(θ)`：发信号的成本——**高质量者发信号更便宜**，信号才可信
- `p(θ)`：先验/基础率（决定阳性预测值）
- 行动者对信号的控制权（能不能选择发/不发/发什么）

**边界条件（缺一即非本模式）**
- 真值**不可直接观测**（只能推）
- 噪声或隐藏**结构稳定**（不是一次性意外）
- 发信号者有激励（否则是纯测量问题）
- 有可用先验或对照组（否则单次观测推不出东西）

**已知同构问题**
- 面试/招聘：能力不可观测，学历与作品是信号
- 品牌/广告：质量不可观测，持续投入是承诺
- 体检/筛查：假阳/假阴，**基础率决定阳性预测值**
- KPI/指标：被测量者会优化指标（Goodhart 定律）
- 评级/信用：用历史行为推断类型
- 逆向选择/柠檬市场：质量不可观测 → 劣币驱逐良币
- 信任：重复博弈里"可验证的付出"

**该类的典型处置动作**
1. **先问"这个数是怎么产生的"，再问"这个数是多少"**：误差不在小数位，在**生成机制**——谁在发、发给谁、为什么现在发。
2. 算**基础率**：`阳性预测值 = f(灵敏度, 特异度, 患病率)`。忽略基础率是这类问题最大的错（罕见病筛查、海投简历的"通过率"）。
3. 用**成本信号**判可信度：可信的信号必须"低质量者模仿不起"——贵、难、可验证、可追责，四者至少占一。
4. 结论形式：`观测 + 噪声结构 + 基础率 + 该信号最可能被操纵的方向`。

**越界后退化成什么**
- 不知道噪声结构（无灵敏度/特异度）→ 只给"可能被高估/低估"的方向，不给概率
- 对抗性极强（对方在骗你）→ 叠 `adversarial-game`
- 观测本身被行动改变（Goodhart）→ 指标失效，必须换成不可操纵的代理指标
- 小样本波动被当信号 → 这是 `sampling-error`（修饰符），不是本模式

**反例（别把它当本模式）**
- 「数据不会说谎」——数据是别人**选择**发出来的信号，说谎的是选择。
- 把单次亮眼表现当能力：`n = 1` 的观测，噪声方差大于个体差异。
- 「他很努力所以可靠」——努力若不昂贵，就不是可信信号（廉价信号无信息量）。
