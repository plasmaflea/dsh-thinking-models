# 反馈环（`feedback-loop`）

**边型**：`X_{t+1} = g · X_t + 外生`（线性环）。环增益 `g = ∏ 各段增益`。
`g > 1` 发散（复利/级联）；`g < 1` 衰减；`g = 1` 恒持或漂移；`g < 1` 但时滞 τ 大 → **振荡**。

**变量集**
- `X`：被放大/衰减的量（用户数、信念、库存、恐慌、债务）
- `g`：环增益（各段乘起来，**不是**感觉上的"有关系"）
- `τ`：回路时滞（决定是单调发散还是振荡）
- `X₀`：初始扰动（决定何时被看见，不决定结局）
- 上限：进入饱和后 `g` 不再是常数（接 `saturation`）

**边界条件（缺一即非本模式）**
- 回路**可闭合**：能指出「输出 → 输入」的具体路径，而不是相关系数
- 各段增益在同一时间尺度上可相乘（无跨尺度重采样）
- 未进入饱和（先按 `saturation` 封顶，再看环）
- 观测窗 ≥ 3τ（否则分不清"在放大"和"噪声在动"）

**已知同构问题**
- 口碑/病毒传播：每用户带来 `g` 个新用户
- 复利/资本回报：存量收益再投资（`r > g` 即马太效应）
- 恐慌/挤兑：挤兑 → 更多挤兑
- 习惯/成瘾：触发 → 行为 → 更强的触发
- 通胀螺旋：工资 ↔ 价格
- 确认偏误：信念 → 选证据 → 更强的信念
- 重试风暴/级联超时：失败 → 重试 → 更多失败

**该类的典型处置动作**
1. **先量 `g`，不要先讲道理**：`g` 是唯一决定"会不会爆"的数。`g < 1` 的环不值得治；`g > 1` 的环必须**打断**，不能只减缓。
2. 打断点在**增益最大且最容易改**的那一段，不在最显眼的那一段；多数情况下**减增益比加阻尼便宜**。
3. 时滞会改变稳定性：`g < 1` 但 τ 大 → 矫枉过正式振荡，此时处置是**降增益或加快反馈**，不是加大力度。
4. 结论形式：`g 的估计 + 双倍时间（或半衰期）+ 打断点 + 打断后 g′ 的估计`。

**越界后退化成什么**
- 进入饱和 → 先按 `saturation` 封顶，环在顶部退化成 S 型曲线（增长放缓但仍在）
- τ 不可测 → 只能给"会/不会放大"的方向，不给时间
- `g` 随人群结构变化 → 分段估，每段单独算 `g`
- 环里有主体在学习/适应 → 转 `adversarial-game`

**反例（别把它当本模式）**
- 「销量涨了说明口碑好」——相关性不是回路；指不出路径就不是环。
- 用「加强管理」处理 `g > 1` 的环：管理动作本身可能是一段新增益（检查 → 对抗 → 更多检查）。
- 把衰减当稳定：`g = 1` 不衰减，只是保持；扰动不会自己消失。
