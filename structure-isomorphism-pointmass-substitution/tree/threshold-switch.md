# 阈值切换（`threshold-switch`）

**边型**：分段常数／分段幂律，**在 `x*` 处不连续**：
`后果 = 0 (x < x*)`；`后果 = 阶跃或发散 (x ≥ x*)`。带滞回时恢复阈值 `x**_r < x*`。

**变量集**
- `x`：连续驱动量（负债率、应力、参与人数、违规率、疲劳循环）
- `x*`：临界值（多数只能估，不能精确测）
- 越线后的新机制（新斜率、新平衡、新失败模式）
- `x**_r`：恢复阈值（滞回：越线后不会自动回来）

**边界条件（缺一即非本模式）**
- 存在**可识别**的切换点（不是把"渐变"误读成"突变"）
- 切换后**机制换了**，不是同一条曲线的陡段
- 驱动近似单调；往复驱动必须带滞回，否则阈值会被低估
- `x*` 落在被观测范围内（否则只是猜）

**已知同构问题**
- 破产/挤兑：流动性跌破阈值 → 瞬间失去偿付能力
- 堤坝/雪崩/林火：应力累积 → 一次释放
- 临界质量/引爆：参与人数过阈值 → 自我维持
- 传染病/免疫：`R₀` 或抗体水平过线
- 破窗/规范崩塌：违规率过线 → 遵守成本突变
- 裁员/组织崩溃：关键人流失过线 → 协作网断裂
- 骨折/材料疲劳：应力循环次数

**该类的典型处置动作**
1. **先找 `x*`，再谈优化**：阈值型问题的全部信息在「离 `x*` 多远」，不在「当前表现多好」——当前表现可以**完全正常直到越线**。
2. 安全边际要用**时间**表示：`剩余时间 = (x* − x) / 速度`；百分比余量在这里没有意义。
3. 处置优先级：**降驱动（减 x）> 抬阈值（改结构）> 加缓冲（吸收阶跃）**。加缓冲最贵，且最容易被误当成解决。
4. 结论形式：`x 当前值 + x* 估计 + 到 x* 的时间 + 越线后换成什么机制`。

**越界后退化成什么**
- `x*` 不可测（只能事后看到越线）→ 给「越线后的形态」+「提前指标」，不给时间
- 有滞回（越线后不自动恢复）→ 必须同时给 `x**_r`，否则会误以为"降回去就好"
- 多阈值串联（级联）→ 叠 `feedback-loop`（越线后正反馈加速）或 `series-reliability`
- 阈值随外部环境漂移 → 只能给"在漂"，不给数

**反例（别把它当本模式）**
- 「性能是慢慢变差的，所以是饱和不是阈值」——阈值问题的观测特征恰恰是**看起来正常，然后突然不行**。
- 把阈值当饱和处理（扩容/加容量）：越线后机制已换，加容量可能完全无效（信任崩塌后加钱无效）。
- 「留了 20% 余量所以安全」——20% 是相对量，危险取决于绝对距离和速度。
