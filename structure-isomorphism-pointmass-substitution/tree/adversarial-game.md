# 对抗博弈（`adversarial-game`）

**边型**：**互定性**（不是乘、不是加）：
`我的收益 = f(我的行动, 你的行动)`，且 `你的收益 = g(你的行动, 我的行动)`。
解不是数值，是**均衡**——双方都没有单方面改变的动力。

**变量集**
- `N`：参与人集（含潜在进入者、监管者）
- `S_i`：各自可行策略集（规则）
- `u_i(s)`：收益（只要能排序，不需要可公度）
- 信息结构：谁在什么时候知道什么
- 一次性 vs 重复（重复会改变均衡，如以牙还牙）
- 承诺能力（能不能把威胁变成事实）

**边界条件（缺一即非本模式）**
- 参与者**有策略**：行动取决于对他人行动的预判，不是固定参数
- 收益可排序（说得出"更想要哪个"）
- 规则（可行策略集）在博弈期间不变
- 单次/重复结构清楚（否则均衡选不出来）

**已知同构问题**
- 价格战/寡头：降价 → 对手降价 → 双输
- 囚徒困境/公地悲剧：个体理性 → 集体非理性
- 谈判/分配：总和固定下的份额之争
- 威慑/军备竞赛：对方加码 → 我加码
- 内卷：相对排名是零和 → 投入升级而收益不变
- 机制设计/激励：改规则比劝人有效

**该类的典型处置动作**
1. **先画策略—收益表，再谈"谁对谁错"**：对抗结构里没有对错，只有「给定规则下的最优反应」。
2. 判定**零和 / 非零和**：零和只能改分配或改规则；非零和优先找共同增益（把蛋糕做大）。
3. 改均衡的三条杠杆，按成本排序：**改支付（激励）> 改可行集（规则）> 改信息（透明度）**。劝说是最弱的一条——它不改变均衡。
4. 结论形式：`当前均衡 + 谁有偏离动机 + 三条杠杆中最便宜的一条 + 对方的最优反应`。

**越界后退化成什么**
- 一方其实没有策略（只是被动参数）→ 退回机制类（流/限）
- 信息不对称是主要矛盾 → 转或叠 `signal-inference`
- 参与者可结盟/可退出（合作博弈）→ 均衡概念要换，本模式只给方向、不给稳定解
- 博弈重复无限次 → 合作可自我维持，结论反转（一次性是背叛，长期是合作）

**反例（别把它当本模式）**
- 「只要大家都有诚意就能解决」——若均衡是囚徒困境，诚意不改变占优策略。
- 把竞争一律当零和：很多"竞争"其实是**信号**（`adversarial` + `signal`），拼的是可信度而不是份额。
- 「他这么做是因为坏」——先问"给定他的位置和规则，还有更好的选择吗"；没有，就是结构问题不是人品问题。
