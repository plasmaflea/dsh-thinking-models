# 🧪 预设答案假设倒推法（反面教材）

**简称**：倒推图（产物：假设—证据链）／倒推法（动作）
**技能 id**：`presupposed-answer-hypothesis-backderivation` ＝ 预设答案·假设·倒推法，与全称三段一一对应

## 它是什么

一句话：**先有答案，再倒着补理由。**

数学类比：给定 x 的公式，问 x 的取值范围 → 先假设 `x>0` → 代入公式看是否成立。

危险不在「先假设」。危险在两件事同时发生：

- 只假设了**自己希望成立的那一种**，不做分类讨论完备性（x=0、x<0 压根没试）
- 假设一被推翻，**换的是检验标准，不是假设**

## 它为什么是反面教材——但它不是纯粹的错

猜想—反驳、分类讨论，都是合法的科学方法。同一个动作堕落成反面教材，需要三个条件同时成立：

1. 假设没有显式声明（读者以为那是事实）
2. 只做确认性检验（找支持证据），不尝试证伪
3. 反例出现后，改的是标准／数据／题面，而不是假设

反过来读就是合法用法：**假设写明 ＋ 试完对立面 ＋ 反例即改假设**。本技能的任务就是把这三条钉回桌面。

## 倒推图的语法

只允许这五列，缺一列作废：

| 列 | 内容 |
|---|---|
| H | 假设本身，必须能被观测判死 |
| E+ | 如果 H 成立，**应该**看到什么（写具体、可观测） |
| E± | 实际看到了什么（没有就写「未检索」，不许留空） |
| 差异 | E± 与 E+ 的偏差 |
| 反例条件 | 什么观测会让 H 死 |

禁止：把 H 写成结论；把「没有证据反对」当成「有证据支持」。

## 六种典型走形（清单 + 检测信号）

| # | 走形 | 典型话术 | 检测信号 | 纠正动作 |
|---|---|---|---|---|
| 1 | 单一假设 | 「假设 x>0，代入成立」 | 没有列出对立情况 | 补全假设集（分类讨论齐全） |
| 2 | 确认性检验 | 「我查了很多案例都支持」 | 检索清单里没有反例 | 证伪先行（先找会打死它的观测） |
| 3 | 反例豁免 | 「那是特例／他不一样」 | 反例被解释掉，而非放弃假设 | 反例优先于解释（先改假设，再谈边界） |
| 4 | 事后改标准 | 「我说的不是这个意思」 | 判据在失败后被修改 | 判据写死（跑之前先把判定程序固定） |
| 5 | 假设升格为事实 | 「事实就是……」 | 前一句还是假设，后一句变成事实 | 假设表分栏（事实／假设／结论逐条标） |
| 6 | 循环论证 | 「因为它是 X，所以表现为 X」 | 前提依赖结论 | 来源独立（换一个不依赖结论的来源） |

## 检测流程（对任何一段回答做审计）

1. **抽命题**：把回答拆成命题，逐条标 `事实` / `假设` / `结论`。**没标的默认是「伪装成事实的假设」**。
2. **补 E+ 与反例条件**：每条假设都要写出期望证据和死亡条件。写不出 → 它不是假设，是叙事。
3. **查检索记录**：反例被找过吗？找到后怎么处理的？没找过 = 走形 2。
4. **查判据是否被移动**：把「跑之前的定义」和「失败之后的定义」并排，看是否一致。
5. **出诊断报告**：命中哪几条 + 纠正映射 + 下一步动作。

## 守 is–ought 线：查 `G` 是否被偷换

六种走形里最隐蔽的两种（#4 事后改标准、#5 假设升格为事实）常常是同一件事的两种说法：**悄悄换了一个 `G`**。

- **事实层**（是什么／为什么／会怎样）→ 换立场不该改变结论；若变了，说明它其实是处置层伪装成事实层。
- **处置层**（好不好／该不该／怎么办）→ 结论**必然**依赖 `G`；**找不到那个 `G` 就是默示**（对持有者有效、对外部不可审计）。
- 检测一问：**把主语换成「你想要什么」，结论变不变？** 变 ⇒ 处置层，必须有 `[G 明示] G = … · 持有者 = … · 成功判据 = …`；对方拿不出，就是默示 `G`。
- 从「是」推不出「该」（休谟）：缺的那个前提就是 `G`。任何把「怎么样」当成「该怎么样」用的推理，都在这条线上断开——不需要参照任何外部方法，`G` 有没有被偷换，只看被审文本自身前后是否一致。

## 独立性：不与其他任何方法耦合

本技能**不引用、不依赖、不假设**任何其他方法或框架的存在。

- 审计对象是**这一段推理本身**：抽命题、补 E+、查检索、看判据有没有移动——四步只用被审文本，不需要任何外部参照。
- 不做「诊断完再转交某个方法」的分工：诊断报告自带纠正动作（补全假设集／证伪先行／判据写死／来源独立），这些动作脱离任何方法都成立。
- 与外部方法**零接口是刻意的**：一旦引用某个框架名或图名，审计就会被读成「那套方法的下游」，独立性作废，被审者的注意力也会从「这条推理哪里断了」漂到「你属于哪一派」。

**禁令**：本技能正文、示例与变更记录里，不得出现任何具体方法名、图名或框架名。要新增一条走形，只描述**推理的行为**（做了什么、漏了什么），不写「应该改用哪个模型」。

## 风险与对策

1. **误判**：合法的假设—检验会被误诊 → 只看三条判据（是否声明、是否证伪、是否改假设），不看符不符合「先有答案」。
2. **只诊断不给方案** → 诊断报告必须附纠正映射与下一步动作，否则是空转。
3. **变成攻击工具** → 诊断对事不对人：审的是「这段推理」，不是「你这个人」。
4. **给不出反例条件** → 该「假设」不可检验，直接判定为叙事，不许进倒推图。
5. **被当成别的方法的前置步骤** → 见「独立性」：本技能只对被审文本负责，不承接任何流程位置。
