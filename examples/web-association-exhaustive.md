# 示例：🕸️ 网状线索关联穷举法（网状图／穷举法）

> 技能 id：`web-association-exhaustive`

## 输入

> 小程序上线两周，次日留存 18%，行业均值 35%。有哪些可能？还有什么没考虑到？

## 产物

```
[🕸️ 网状图] 选择理由：问的是「有哪些可能」，要的是覆盖度而非单一结论；
     且线索之间本身有关联（渠道 → 人群 → 内容 → 触达），适合先建网再穷举。

关系语法：关联边 A — B 带权（物理距离 / 关联度）；无关边 A ⊥ B 附阈值

| 线索 | 假设 | 证据 | 可能性 | 结论 |
|---|---|---|---|---|
| 渠道结构 | 买量占比高，人群与产品不匹配 | 后台渠道表：自然流量仅 12% | 高 | 保留 |
| 价值到达时间 | 用户当天没触达核心功能（如建第一个项目） | 埋点：D1 核心功能触达率 23% | 高 | 保留 |
| 通知触达 | 无召回触点，纯靠用户自发回访 | 未接订阅消息 | 高 | 保留 |
| 首启体验 | 首屏加载 >3s 导致次日不回 | 缺首屏耗时分位数据 | 中 | 待验证 |
| 统计口径 | 留存分母与行业口径不一致（新用户 vs 全量） | 需核对分母定义 | 中 | 待验证 |
| 竞品替代 | 同类小程序在做补贴，短期分流 | 无直接数据，仅行业传闻 | 低 | 排除 |

关联边（带权，说明取哪个度量）
  渠道结构 — 价值到达时间：强（同源人群，权重取"物理距离"＝同一批用户）
  价值到达时间 — 通知触达：强（触达率低 ⟺ 无召回手段，互补而非重复）
  首启体验 — 统计口径：弱（仅在前两条都不成立时才值得查）

无关边（阈值 + 理由）
  竞品替代 ⊥ ：行业补贴渗透率 <5%，阈值取 10%，低于阈值即排除
  客服响应 ⊥ ：与"次日"时间尺度不匹配（工单量 << 次日流失量）

假完备自检（这一步不能省）
  有没有哪类线索我根本没列成行？
  → 补一行「产品价值本身是否有问题」；该行无证据，标待验证，不强行下结论。

收敛（保留项按杠杆排序）
  1) 价值到达时间——触达率 23% 意味着大多数人第二天没有回来的理由
  2) 渠道结构——自然流量仅 12% 时，"留存"本质是买量人群质量指标
  3) 通知触达——零召回手段，等于主动放弃次日

待验证（缺什么证据才能定案）
  - 首屏耗时 p75 → 决定「首启体验」是否升进保留项
  - 留存分母口径 → 决定 18% 这个数字本身是否成立
```

## 为什么这样比直接回答好

- **每行都有状态**，没有一行悬空：不确定的被显式标成 `待验证` 并写明缺什么证据
- **「统计口径」是穷举逼出来的**：直接回答往往照着 18% 这个数字往下推，从不怀疑分母
- **负边留档**：排除项与阈值都可复核，证明是「想过并剪掉」而不是「没想到」
- **假完备自检**：表满 ≠ 全覆盖，最后一行自问才能补出漏掉的整类线索
