# 📐 经验公式质点代入法

用于预测估算、建模推演、迭代优化。产物是**一个公式（或类比）+ 它的适用边界**。

## 流程

抽象化 → **将问题简化为质点（单自由度/核心变量）** → 选定经验公式或类比 → 代入运算 → 迭代收敛。

## 代入前必须说明两件事

1. 被代入的经验公式/类比是什么（出处、适用条件）；
2. **质点模型的简化假设与边界**在哪。

没说清这两条就代入，等于编数。

## 质点模型说明

把复杂对象抽象为一个质点，明确其自由度与受力/约束，便于借用成熟领域的经验公式（如力学、动力学类比）。质点化是建模手段，不意味着忽略内部结构——被省掉的自由度必须在假设里点名。

## 风险与对策

**过度简化** → 每次迭代标注简化点（质点忽略了哪些自由度），收敛时检查假设是否被事实推翻。

## 与其他模式的关系

- 穷举优先于质点代入法：路径没穷尽之前不要急着建模。
- 建模前若核心概念边界模糊，先做定义前置。

## 输出骨架

```
[📐] [选择理由]
经验公式/类比：<公式 + 出处 + 适用条件>
质点模型：<核心变量 + 自由度 + 被忽略的自由度>
代入：<数值与单位>
迭代：<轮次 → 修正点 → 收敛判据>
结论：<量级 + 误差范围 + 假设被推翻的条件>
```
