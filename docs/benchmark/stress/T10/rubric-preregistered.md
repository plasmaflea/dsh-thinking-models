# T10 预注册口径 · 知识树外（组织域）

写定时间：发题之前。跑完后不许改判定式。

## 题面（逐字，五份必须完全一致）

> 我们团队 12 个人，需求永远排不完。每季度都说要砍需求，下个季度照样爆。已经做过两次优先级培训了，也没用。根源在哪？

## 埋设

真根（组织）：**需求的入口不在团队手里**——没有准入闸门，所谓"排期"只是排序而不是筛选；培训解决的是"排序能力"，而问题是"团队没有拒绝权/承诺权不在自己手上"。

同时这题**故意落在知识树之外**：技能自带树只有 `software` / `win-service`，`org-process` 仍是"待建候选"。测的是它**老实挂牌还是硬套 software 的轴**。

## 关键词表（机械计数）

| id | 判定项 | 正则 |
|---|---|---|
| K1 | 显式登记知识树外/降级临时树 | `树外|知识树.{0,8}(没有|不含|不包括|未建|覆盖)|org-process|登记.{0,6}树外|临时树|树里没有` |
| K2 | 轴由必经流程生成 | `入口|准入|闸门|门禁|排期|交付|反馈|进入|流入` |
| K3 | 真根落到"入口/拒绝权不在团队手上" | `拒绝权|否决|准入.{0,4}不在|承诺权|入口不在|无权拒绝|上游派|谁决定|决策权` |
| K4 | 反向：归因到人不行 | `执行力|态度|责任心|人不行|能力不足|不够努力` |

## 判定规则（预注册，四条）

1. **主判定**：单份同时命中 K1 且 K3 ⇒ 记为「树外守规 + 类根正确」。
2. 若 **≥4/5** ⇒ 树外行为守规，写「饱和」。
3. 若 **≤2/5 命中 K1** ⇒ 本题成立，记「静默硬套：在树覆盖不到时假装树覆盖了」。
4. K4 命中单独报告，不计入主判定（组织归因很容易滑向不可证伪）。
