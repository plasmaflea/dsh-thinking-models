# 林状图 v4 评分口径（10 项）

> v4 把「根」从个例上移到大类，旧 8 因子只量个例根，已不足。本轮起改用下列 10 项。
> 判定：✅ 完整出现 / ⬜ 提到但不成形 / ❌ 缺失 / n.a. 该题不适用。

| # | 项 | 判据（什么算 ✅） |
|---|---|---|
| 1 | L0 类别判定 | 显式一行写出「这是哪一类问题」，给出判据，并写出**已排除**的大类 |
| 2 | L1 树实例化 | 引用知识树节点并写出 `树 = <节点> · vN · 核查 <日期>` |
| 3 | L1b 树外分支登记 | 树里没有的分支进挂起表或标 `v(N+1) 候选`，不静默丢弃 |
| 4 | L2 回溯到类根 | 根落在「这一大类在什么结构条件下才可能发生」，不是「这次怎么了」 |
| 5 | L2b 个例根挂类根下 | 个例根是类根的子节点，不是与类根并列的清单 |
| 6 | L3 处置根 | 有「修本次」的根，且可执行 |
| 7 | L3b 消解根＋不可发生判据 | 有「灭这一类」的根，且写明「若当时采用它，本类问题结构上不可能发生」 |
| 8 | L3c 消解根可执行首边＋成本量级 | 写出从现状出发的第一步（可以很小）与成本量级 |
| 9 | L4 迁移出口 | 指向换系统／换结构时，列出后续问题清单，并**把本次问题降级为其中一项**；不指向换系统则 n.a. |
| 10 | 挂起表四列 | 分支／判定／依据／**恢复条件**，禁止用删除代替挂起 |

## 与 v3 的差异

- v3 的「题面因子命中表」仍然是并列表，但只用于量**个体根覆盖**，不再作为总分。
- v4 的总分是 10 项判定，**不做加权**——每项要么出现要么没有，避免把「写得多」当成「想得深」。

## 计分

```
总分 = ✅ 数 ÷ 适用项数（n.a. 不计入分母）
```

同时记录三项过程量：字符数、表格行数、挂起表条数。
