# 800 访问/月、AdSense $5/月：除「多写文章」外的增长路径

> 🕸️ 网状图／穷举法 —— 选它的理由：这是「还有哪些路径」型问题，需要先穷举再收敛排序，不能一上来就押注单一方案。

## 0. 先做数学体检（它决定后面所有优先级）

| 量 | 数值 | 含义 |
|---|---|---|
| 月访问 | 800 ≈ 27/天 | 这个量级下任何广告优化都是噪声 |
| 月收入 | $5 | — |
| 千次访问收入（RPM） | 5 ÷ 800 × 1000 ≈ **$6.25** | 技术类 AdSense 常见区间 $2–8，你在**上沿** |
| 广告变现天花板 | 800 × $15 RPM = **$12/月** | RPM 翻 2.4 倍也只多 $7 |

**三条结论，先把它们钉住：**

1. **在当前流量下，广告变现没有优化空间，只有量级问题。** 你花一周把 RPM 从 $6.25 提到 $12，月收入从 $5 变 $10。这不是增长，这是零花钱。
2. **你的变现效率不差，差的是流量基数和流量意图。** RPM 在上沿说明来的人还算「值钱」，但 800 这个基数太小，且大概率以「信息型查询」为主（想搞懂，不想买）。
3. **三年做到 800/月，问题不在勤奋，在结构。** 三年足够让一批文章稳定吃长尾。停在 800，通常意味着：选题没对准搜索需求、内容之间没形成集群、或者压根没有分发渠道（只有 Google 一条腿）。

### 一个 15 分钟的自检（决定你该走哪条路）

打开 Google Search Console → 效果：

- **有曝光但 CTR < 1% 的查询有多少条？** → 纯白捡的流量，改标题/描述就能拿。
- **平均排名在 5–20 位的页面有多少？** → 差一口气，最容易推到首页，比新文章 ROI 高一个数量级。
- **曝光量前 20 的页面里，有几篇是两年前写的？** → 如果全是，说明你在吃老本，没有新增量。
- **有没有几篇文章抢同一批关键词？** → 内耗，互相稀释排名。

这四个数字决定你 70% 的行动。**在没看这四个数字之前，任何「增长策略」都是猜。**

## 1. 存量资产化：不写一个新字，把三年内容榨出 2–3 倍流量

这是**成本最低、见效最快**的一条路，也是绝大多数人跳过的一条。三年内容 = 一个已经跑过沙盒期、有历史权重、有真实排名的资产池，而「多写」是在池子外面重新挖坑。

| # | 动作 | 具体怎么做 | 典型效果 |
|---|---|---|---|
| 1 | **CTR 手术** | GSC 筛「曝光 > 500 且 CTR < 1%」的页面，只改 `<title>` 和 meta description：加具体收益、加年份、加数字、加对比（「X vs Y」）。改完在 GSC 里请求重新抓取。 | 单页点击量 2–5 倍，2–4 周见效 |
| 2 | **意图重写** | 找出「排名不错但停留 < 30 秒 / 跳出 > 85%」的文章。排名好说明关键词对了，跳出高说明**内容形态错了**（人家要代码，你写散文；人家要结论，你写心路历程）。改成「结论先行 + 可复制代码 + 踩坑清单」。 | 停留时长、回访、转化同时改善 |
| 3 | **建内容集群 + 强制内链** | 把同主题文章收成一个 pillar（总览）+ 若干 cluster（细分）。每个 cluster 页首段链回 pillar，pillar 逐个链到 cluster。**每篇至少 3 条出链 + 被 3 条入链。** 这是 topical authority 最便宜的来源。 | 集群整体排名抬升，长尾互相带 |
| 4 | **合并薄页** | 3 篇各 600 字讲同一件事的文章 → 合成 1 篇 2000 字。老 URL 301 到新 URL。薄内容互相竞争是排名杀手。 | 消除关键词内耗 |
| 5 | **更新 + 时效信号** | 每年过一遍：装不上的版本、失效的 API、过期的截图。改完更新 `dateModified` 和页面上的「最后更新」字样。技术内容的「过期」是最大的隐性流量漏点。 | 恢复下滑页面的排名 |
| 6 | **结构化数据** | 加 `TechArticle` / `FAQPage` / `HowTo` / `SoftwareApplication`。技术博客基本没人做，做了就是差异化。 | 富结果、CTR 提升 |
| 7 | **首屏与性能** | 技术博客的头号杀手是「首屏一个 3MB 的 GIF + 4 个广告位」。LCP < 2.5s、CLS < 0.1。**AdSense 在你这个量级带来的 $5，抵不上它拖慢页面造成的跳出。** | 排名因子 + 体验 |
| 8 | **页面级 CTA 重排** | 每篇文章末尾按类型给一个**唯一**的下一步：教程类→订阅；对比类→联盟链接；踩坑类→「我帮你排坑」咨询页。现在你大概率是 0 个 CTA，或全是 AdSense。 | 同流量下收入/订阅翻倍 |

> **这一节的关键判断**：如果你的 GSC 里有 10 个以上「排名 5–20 + 有曝光」的页面，那么**未来 90 天你一篇新文章都不该写**，全部精力投到 1/2/3 上。这通常能带来 30–100% 的流量提升。

## 2. 分发：不产新内容，把存量推到 8 条渠道上

你现在大概率只有「Google 自然搜索」一条腿。单腿走路的博客，流量上限就是你的 SEO 水平。分发不是「发个链接」，是**按渠道的语法重写一次入口**。

| 渠道 | 具体做法 | 备注 |
|---|---|---|
| **搜索引擎多元化** | Bing Webmaster、Yandex、Naver、Brave Search 各提交 sitemap。Bing 顺手喂 IndexNow。 | 一次性配置，白拿 5–10% 增量 |
| **技术社区** | Hacker News（周二至周四早 8–10 点 ET）、Lobsters、r/programming、V2EX、掘金、即刻。**不要发「我写了篇文章」，发「我发现了一个反直觉的事」。** | 单篇爆一次 = 几千访问 |
| **聚合站 canonical** | Dev.to / Hashnode / Medium 同步全文并设 canonical 指回原站。**平台自带流量，Google 不判重复。** | 最被低估的白拿渠道 |
| **GitHub** | 文章里的脚本/配置/模板抽成 repo，README 顶部放「配套文章」链接。GitHub 搜索流量巨大且精准。 | 技术博客最强反链来源之一 |
| **Newsletter 互推** | 找 3–5 个量级相近（500–5000 订阅）的同行做互相推荐位。**等价交换，不用花钱。** | 冷启动邮件列表最快的方式 |
| **Awesome-list / 资源页** | 你的工具、教程进对应 awesome-xxx 仓库。一个 PR 换一条永久高质量外链 + 持续流量。 | 长期复利 |
| **问答区** | Stack Overflow、GitHub Issues、Reddit 里真回答问题，末尾附自己文章。**必须先真解决问题，否则是垃圾。** | 转化率极高 |
| **视频/音频拆解** | 一篇深度文 → 一个 3 分钟录屏 → YouTube/B站；或去做客播客。同样的内容，第二个分发面。 | 边际成本低 |

> 一条纪律：**每篇新文章，发布后 48 小时内必须推满 5 个渠道，否则等于没写。** 大多数人的问题是写完就等 Google。

## 3. 把一次性流量变成可反复触达的资产（如果只做一件事，做这个）

800 访问/月 = 每个月有 800 个陌生人路过你家门口，然后走进黑洞。**三年下来你损失了一个几千人的邮件列表。** 这是整份答案里唯一真正「复利」的资产。

具体做法：

1. **做一个免费磁铁**（不要「订阅我的博客」，没人要）。技术博客最好用的磁铁：
   - 你踩过的坑的 checklist（PDF/Notion）
   - 一份可跑的 boilerplate / 配置模板
   - 一张对比速查表（cheat sheet）
   - 一个小工具（在线格式化、计算器）
2. **放在文章正文中段**（不是末尾），用「想要这份 X 的，留个邮箱」。
3. **双周发一封**，内容 = 一篇新文摘要 + 一条只有订阅者看到的东西（行业内幕、失误复盘、early access）。
4. **退出率控制**：一封只讲一件事。

> 量化直觉：**1000 个真订阅者 ≈ 每次发信 300–500 访问 + 一个可以卖东西的通道**。它比 10 万随机 PV 值钱，因为它可重复触达。而且邮件列表是你唯一不受算法更新影响的资产——Google 一次 core update 就能让你的 800 变 200。

## 4. 变现结构升级：同样的 800 访问，收入 3–20 倍

AdSense 是所有变现方式里 RPM 最低的一档。**不换流量，只换变现方式**，也能立刻改变收入量级。

| 方式 | 门槛（以官网为准，会变） | 预期 | 适合你吗 |
|---|---|---|---|
| **AdSense（现状）** | 无 | RPM $2–8 | 天花板已到 |
| **Ezoic** | 门槛低，官方称适用各种规模 | RPM 通常比 AdSense 高 50–200% | ✅ 立刻可做的第一步 |
| **Mediavine** | 约 50k sessions/月 | RPM 更高 | ❌ 暂时够不到，作为目标 |
| **Raptive (AdThrive)** | 约 100k pageviews/月 | 最高档 | ❌ 远期 |
| **Carbon Ads / 开发者广告网** | 需申请，看受众质量 | CPM 高于通用广告 | ✅ 技术受众匹配度高，值得试 |
| **联盟营销** | 无门槛 | 开发者工具联盟常见 20–30% 循环佣金或 $50–200 一次性奖励（具体看各家条款） | ✅ **最高优先级**。你写教程时天然会提到工具 |
| **赞助位** | 无门槛 | Newsletter 赞助经验值 CPM $20–40；500 订阅的小列表也能卖 $20–50/期 | ✅ 有列表后才成立 |
| **数字产品** | 无门槛 | 模板/boilerplate/电子书 $19–99 | ✅ 一次性做，长期卖 |
| **付费会员/深度内容** | 需要已有信任 | $5–10/月 | ⚠️ 800 流量太早 |
| **咨询 / 接单 / 顾问** | 无门槛 | 单笔 $500–5000 | ✅ **单价最高、最该立刻开的** |

**两个最被忽略的点：**

- **联盟营销是技术博客的天然变现方式。** 你写「我怎么部署的」，本来就要提 Vercel/Cloudflare/Supabase/Neon。挂上联盟链接是零额外成本。**前提：只推你真在用的**，否则读者一眼看穿，信任一次性烧光。
- **咨询页比广告值钱一万倍。** 800 访问/月里只要有 1 个人因为「这哥们懂这个」来找你，一单就超过你 3 年 AdSense 总和。在 About 页和每篇踩坑文末尾放一个「我可以帮你排这个坑」的入口。

> **战略岔路（很重要）**：800 访问追广告收入是死路。真正的选择是——
> **A. 少流量 × 高单价**：不追 PV，追「能被搜到的专业身份」，变现靠咨询/产品/赞助。
> **B. 大流量 × 低单价**：走程序化 SEO 冲 5 万 PV，再吃 Mediavine。
> 这两条路的动作完全不同。**先选路，再谈执行。** 混着做会两头不到岸。

## 5. 换内容形态，而不是多写字数

「多写文章」的问题是它是**线性**的。下面这些是**非线性**的——一次投入，持续产出。

1. **Programmatic SEO（模板化页面）**
   用一套模板批量生成结构化页面，每个页面命中一个长尾查询。技术博客天然适合的模板：
   - `X vs Y`（工具/框架对比）
   - `How to <do something> in <language/framework>`
   - `<error message>` 错误码解释页
   - `<tool> 配置示例`
   100 个模板页 × 每个 20 访问/月 = 2000 访问/月，而且这些页面**自动互链**成集群。注意：必须是**有真实差异的内容**，纯 AI 灌水会被 Google 的 scaled content abuse 政策打掉。

2. **交互式工具页（最高杠杆）**
   一个在线计算器 / 格式化器 / 对比器 / 转换器。特点：① 用户会主动搜 ② 别人愿意链 ③ 停留时间长 ④ 一个工具页能顶 50 篇文章的外链能力。技术博客做工具的门槛极低。

3. **年度原创数据报告**
   「我跑了 100 个框架的 benchmark」「我抓了 5000 条招聘数据看技术栈趋势」。**原创数据是外链磁铁**——别人要引用就必须链你。这是拿高质量外链最正当、最有效的方式，一年一篇就够。

4. **术语表 / 知识库页**
   50–200 个短定义页，互相内链。低成本吃「什么是 X」型查询。

5. **资源聚合页（linkable asset）**
   「我精选的 50 个 XX 工具」。这类页面天生容易被人收藏和引用。

## 6. 拿外链：被引用，而不是去求

不要去买外链、不要去论坛刷链接（负边里单列）。技术博客的正确姿势是**生产「必须被引用」的东西**：

- **原创图表/数据**（别人写文章要引用就得链你，且图表自带署名）
- **开源工具 + 配套文章**（GitHub star → 自然外链 → 搜索权重）
- **记者/媒体引用**（HARO/Connectively 类服务，回答技术类提问）
- **同行客座/专访/播客**
- **本地技术 meetup 分享**（现场一次，回头一条 .edu 或社区站外链）

## 7. 定位收窄：这可能是真正的根因

三年 800/月，一个高频解释是：**你什么都写，所以搜索引擎不知道该把你排在谁前面。**

诊断方式：把你的文章标题读一遍，问——**「这个博客用一句话说，是讲什么的？」** 如果你要用三句以上才能说清，问题就在这。

- 选一个**交叉点**：`你的独特经验 × 有人搜 × 有商业价值`。比如不是「前端」，而是「用 Rust 写 WASM 插件的前端性能优化」。
- **老文章不用删**，但新方向必须垂直。把老文章逐步 301 或降级到 `/archive/`。
- 定位收窄后，内容集群、内链、外链、变现**全部同时变容易**——因为一切都有了共同指向。

## 8. 如果你每周只有 10 小时：90 天优先级

按 ROI 排序，不要并行做五件事。

| 阶段 | 做什么 | 预期 |
|---|---|---|
| **第 1–2 周** | GSC 全量审计（第 0 节的四个数字）→ 挑出 10 篇「差一口气」的页面 | 拿到行动清单 |
| **第 3–6 周** | 这 10 篇：改标题 + 补内容 + 建内链集群 + 结构化数据 | 流量 +30–80% |
| **第 2 周起并行** | 上线邮件磁铁 + 订阅框（放正文中段） | 开始攒资产 |
| **第 4 周** | 换 Ezoic + 开始挂 2–3 个真实在用的联盟链接 + 上线咨询页 | RPM 与客单价同时抬 |
| **第 7–10 周** | 每篇存量文推 3 个分发渠道（GitHub / Dev.to / 社区） | 拿到第一波外部流量 |
| **第 11–13 周** | 做 1 个工具页 或 1 篇原创数据报告 | 开始拿自然外链 |
| **持续** | 双周 newsletter | 复利 |

## ⬛ 负边：明确不要做的事（附理由）

1. **不要买流量、刷 PV、互点。** AdSense 账号会被封，且封了申诉基本无门。你为 $5/月 冒这个风险是荒谬的。
2. **不要批量 AI 生成灌水页。** Google 的 scaled content abuse 政策专门打这个，惩罚是整站级的。程序化 SEO 的前提是「每个页面有真实差异化信息」。
3. **不要去买外链 / 群发外链。** 低质量外链现在是负资产。
4. **不要在 800 流量时死磕广告优化。** RPM 优化在这个量级是数学上的噪声（见第 0 节）。先把基数或单价抬起来。
5. **不要频繁换主题、换域名、换 CMS。** 每一次迁移都在重置你三年积累的一点东西。你现在最缺的就是「积累」。
6. **不要同时开 5 个分发渠道。** 渠道有启动成本，5 个半死的渠道不如 2 个活的。先做透 2 个（GitHub + 一个社区）。
7. **不要保留 AdSense 如果它明显拖慢页面。** 技术读者对广告容忍度低。$5/月 换来的体验损失，可能正在吃掉你的回访和订阅。

---

## 结论：三句话

1. **先别写新文章。** 你现在最大的浪费是三年存量内容没被结构化、没被内链、没被分发——这是零成本翻倍的空间。去 GSC 里找那 10 篇「排名 5–20」的页面。
2. **AdSense 这条路在你的流量下是死的，立刻换变现结构。** Ezoic + 真实联盟 + 一个咨询入口，同样的 800 访问能做到 $30–80/月，且不依赖流量增长。
3. **唯一值得长期投入的资产是邮件列表和「被引用的原创内容」。** 前者抗算法，后者拿外链。写文章只是喂给它们的原料。

> **最后一句实话**：$5/月 = 一年 $60。三年内容资产值这个数吗？要么认真把它当资产运营（选 A 或 B 一条路走到底），要么坦然承认它是爱好、关掉广告、把时间还给自己。**最耗人的是中间态——半认真，且期待广告养站。**
