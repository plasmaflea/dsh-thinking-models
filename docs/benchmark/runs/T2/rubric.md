# T2 判分口径（rubric-t2）— 跑之前定死

> 铁律：本表在五个 agent 开跑前写定，之后不得因结果好坏改判据。
> 题目难度：**D10 只有相关性，根不可达**（无假证据、无实现代码可读）。

## 一、五项判定（每项 0 / 0.5 / 1，满分 5）

| # | 判定项 | 1 分（做到） | 0.5 分（部分） | 0（没做到） |
|---|---|---|---|---|
| 1 | **时间线折价** | 明确指出下降起点在 **10-08**，并据此把 PostgreSQL 升级（10-09）与大促（10-10）降级为放大器/无关 | 提了时间先后但没据此降级，或只降级了其中一个 | 把 DB 升级或大促当根，或完全没看时间线 |
| 2 | **反向证据折价** | 发现 **Web 端失败率从 2.8% 降到 2.3%**，并据此否定/大幅下调 CDN 作为根 | 提到 CDN 可能无关但没引用 Web 反证 | 把 CDN 当根，或没提 Web 这一列 |
| 3 | **不可判定性** | 明确说出「v3.4 与 CDN 同日发布，现有聚合数据无法分离」 | 说「可能都有影响」但没点出同日不可分离 | 硬给单一根且不声明不确定性 |
| 4 | **区分性观测** | 给出 ≥2 个能把 v3.4 与 CDN 分开的最小观测（如按 WebView 版本/机型细分 JS 错误、CDN 单地区回切做对照、查 v3.4 灰度名单与实际放量、对比静态资源域名与 API 域名路径） | 只给 1 个，或给的是「加监控」这类不能分离的 | 只给「多观察/继续排查」 |
| 5 | **结构完整** | 有类别判定、假设表（含反例条件／恢复条件）、排序、结论，且结论层显式分级（确诊/主嫌疑/未排除） | 有结构但缺分级或缺挂起项 | 平铺直叙无结构 |

## 二、附加观察（不计分）

- **是否回滚式建议**：若建议「先回滚 v3.4」，有没有声明此时 CDN 仍在、观测无法归因。
- **是否追问缺失数据**：有没有主动指出「网关原始报文不留存」导致哪一项不可判。
- **是否处理「其他」占比 9%→17%**：这一项其实也指向「失败被重新分类」，观察到算加分项（不计分）。
- **成本**：字符数、表格行数、章节数、挂起/假设表条目数。

## 三、跑法

- 5 个独立 agent（a–e），同一题面逐字、互不可见，都只给 `lab-t2\data.md` 路径，不被告知用哪个技能。
- 产物写入 `D:\DeepSeek-levelup\runs-staging\T2\agent-{a..e}.md`，末尾须自报 `[技能] <id>`。
- 路由观察：自报技能是否等于 `forest-hierarchical-backtracking`。

## 四、预注册的判读规则

- 若 **≥4/5** 在第 1、2、3 项满分 ⇒ 该题也不构成 D10 压力，下一轮须换成「数据本身有采样偏差」的题（D10'）。
- 若 **≥3/5** 在第 3 项为 0（硬下单一根） ⇒ 记录为「林状图在『变更同日、聚合不可分离』题型上的过度断言」，直接进论文 limitations。
- 若 **≥3/5** 把 CDN 当根且未引用 Web 反证 ⇒ 记录为「最显眼指标优先于反向证据」，这是比单题正确率更值得写的发现。
- 若 ≥4/5 在第 4 项为 0（给不出可分离观测） ⇒ 说明技能只产出「结构」不产出「下一步可执行动作」，需在技能里补一条强制出口。
