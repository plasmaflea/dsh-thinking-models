# before / after 对照：三种逻辑模型技能是否改变输出

## 这是什么

同一个问题，问两次：一次给一个**没有装这三个技能的模型**（before），一次给**装完的模型**（after），把两份原文并排放，用**跑之前就定死的指标**去数差异。

不是 benchmark 排行榜。样本量 1，单次运行，目的是**证明差异存在且可被计数**，不是证明"平均提升 X%"。

## 三个题面

| # | 模式 | 题面 | 为什么选它 |
|---|---|---|---|
| 1 | 🌳 林状图 | 我们有一个 Node.js 服务部署在 Windows Server 上，用 NSSM 托管成 Windows 服务。近期偶发：服务启动后进程立刻退出，事件查看器里只有 exit code 3221225794，没有堆栈，没有 stdout 输出。已经排查过环境变量和文件权限，看起来都正常。根源在哪？ | **有客观答案**：`3221225794` = `0xC0000142` = `STATUS_DLL_INIT_FAILED`。说不出这个码值语义就是没查到根 |
| 2 | 🕸️ 网状图 | 我的个人技术博客写了三年，现在月访问量 800，AdSense 月收入 5 美元。除了「多写文章」之外，还有哪些可行的增长路径？ | **可判定覆盖**：路径类别（变现结构／已有资产／流量来源／外链／形态／算法适配）事后可数 |
| 3 | 📐 公式图 | 帮我估算：3 人团队（1 前端、1 后端、1 全栈兼产品），6 个月做一个类似 Notion 的块编辑器 MVP，大概需要多少人日？ | **有量级答案**：3 人 × 6 月 × 20 天 ≈ 360 投入人日。不给假设的估算等于拍脑袋 |

## 指标（跑之前定义）

| 指标 | 定义 | 判据 |
|---|---|---|
| 命中率 | 真实因素命中数 ÷ 真实因素总数 | 第 1 题的真实因素集见下 |
| 无关项率 | 写进主因但实际无关的条数 ÷ 主因总数 | 靠堆数量装全面的回答会在这列露馅 |
| 负边留档 | 是否写成"已排除 / 无关"条目并附理由 | 有 / 无 |
| 假设显式化 | 是否给出取值、依据与"假设被推翻会怎样" | 有 / 无 |
| 可执行排序 | 是否给出"先查什么后查什么"的顺序及判据 | 有 / 无 |
| 成本 | 输出行数 / 字符数 | 由脚本数，不采信自述 |
| 修一次的成本 | 追加一条新信息后，需要重写的比例 | 待补做 |

第 1 题的真实因素集（用于命中率计数）：

1. `3221225794` = `0xC0000142` = `STATUS_DLL_INIT_FAILED` 的码值语义
2. 失败发生在 `DllMain` 阶段、入口点之前（这解释了"无 stdout、无堆栈"）
3. Session 0 / 非交互窗口站
4. 桌面堆耗尽（`SharedSection`）
5. DLL 搜索顺序 / 应用目录影子 DLL
6. `AppInit_DLLs`、杀软注入等非预期 DLL 注入
7. SxS 配置错误
8. 受限令牌 / 低完整性级别导致 DLL 初始化失败

## 对照组（before）结果 — 待补

将同一三个题面贴到一个**没装这三个技能的宿主**（DeepSeek 网页版等），整段复制回填。在此之前本页只有实验组，**不构成对照结论**。

## 已经能看出的三件事

1. **路由有效**：三个 subagent 只收到题面、未被告知用哪个技能，全部命中了对应的那一个（3/3）。说明 `description` 的触发词设计能撑起自动分发。
2. **负边是结构性差异，不是风格差异**：三份产物都强制交付了"排除项 / 被忽略项"（10 / 14 / 16 条），且每条带理由或回代代价。自由推理通常没有这一节。
3. **⚠️ 结构化穷举也有盲区**：`forest.md` 的 14 条候选里**没有**「受限令牌 / 低完整性级别」这一条（实测关键词命中 0 次），而它恰好是我们在 DSH 沙箱场景里遇到的真实根因（`WRITE_RESTRICTED` + Low 完整性导致 `0xC0000142`）。命中 6/8，漏的两条正是最难想到的那类。**这条要写进论文的 limitations，不能藏。**

## 方法上的诚实声明

- 单次运行、每条件 n=1，LLM 输出有随机性，本页不放"提升百分比"
- 实验组由同一模型族生成，对照组宿主不同 ⇒ 差异里混有"宿主差异"成分。要隔离这一项，需要对同一模型做"装/不装"的同宿主对照，这属于论文阶段的受控实验
- 行数、字符、条目数由 pwsh 实测；**模型的自述数字不可采信**（实测一例：自述 161 行，磁盘 212 行，偏差 51 行）
- 第 1 题的"真实因素集"由作者枚举，本身可能不完整——这也是为什么第 3 条发现（漏掉令牌/完整性）比命中率更有价值
