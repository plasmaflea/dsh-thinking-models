# v2 对照题面（定稿，逐字使用）

## 使用规则（违反任何一条，本次数据作废）

1. **逐字**粘贴，一个字都不改。不要在题面前后加任何话——不要写"请用林状图"、不要写"要穷举"、不要写"标出负边"。
2. 每个题面开一个**全新会话**，不要在同一会话里连问四题。
3. 贴完**不要追加任何引导**：不解释、不追问、不补信息、不纠正。
4. 回答完整留存，不删减、不摘要。
5. four 题跑完再统一回填，别中途改题面。

## 四个题面

### 题面 1（排障 / 对应 🌳 林状图）

```
我们有一个 Node.js 服务部署在 Windows Server 上，用 NSSM 托管成 Windows 服务。近期偶发：服务启动后进程立刻退出，事件查看器里只有 exit code 3221225794，没有堆栈，没有 stdout 输出。已经排查过环境变量和文件权限，看起来都正常。根源在哪？
```

### 题面 2（方案穷举 / 对应 🕸️ 网状图）

```
我的个人技术博客写了三年，现在月访问量 800，AdSense 月收入 5 美元。除了「多写文章」之外，还有哪些可行的增长路径？
```

### 题面 3（估算 / 对应 📐 公式图）

```
帮我估算：3 人团队（1 前端、1 后端、1 全栈兼产品），6 个月做一个类似 Notion 的块编辑器 MVP，大概需要多少人日？
```

### 题面 4（结论审计 / 对应 🧪 倒推图）

```
团队复盘得出的结论是：「新用户留存低，是因为注册引导流程太长」。手上的证据只有三条：(a) 三个月前我们把引导从 7 步压到 3 步，留存曲线几乎没有变化；(b) 竞品的留存比我们高，而它们的引导比我们更长；(c) 留存最低的那批用户来自一个没走过 AB 实验的渠道。老板要求下周一按这个结论立项改引导。这个结论成立吗？
```

题面 1 的 8 因子真因集（命中率用）：

1. `3221225794` = `0xC0000142` = `STATUS_DLL_INIT_FAILED` 的码值语义
2. 失败发生在 `DllMain` 阶段、入口点之前（解释了"无 stdout、无堆栈"）
3. Session 0 / 非交互窗口站
4. 桌面堆耗尽（`SharedSection`）
5. DLL 搜索顺序 / 应用目录影子 DLL
6. `AppInit_DLLs`、杀软注入等非预期 DLL 注入
7. SxS 配置错误
8. 受限令牌 / 低完整性级别导致 DLL 初始化失败
