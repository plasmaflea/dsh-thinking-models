# 论文流水线：把《科研论文提示词》映射到本项目的论文

> 参考来源：`科研论文提示词.txt`（826 行）——25 个阶段 / 9 个阶段组 / 3 个门控（5、9、20）/ REFINE·PIVOT 决策循环 / 反幻觉红线 / 逐阶段 system-user 提示。

## 一、先承认一个结构性错配

那份提示词是**ML 实验型论文**的流水线：它假设有数据集、基线、Loss 曲线、GPU、可消融的模块。它把「跑实验」当作证据的唯一来源。

我们这篇不是那个形状：

| 它的假设 | 我们的实际 |
|---|---|
| 证据 = 训练/评测曲线 | 证据 = 人工评测 + 受控对照（n≥10）+ 标注一致性 |
| 贡献 = 新算法 + 更强指标 | 贡献 = 新**方法**（三种关系语法 + 负边纪律）+ 可审计性指标 |
| 可以消融「模块」 | 只能消融「纪律」：去掉负边栏、去掉假设表，看产物质量怎么塌 |
| 有现成 benchmark 可打榜 | 没有现成 benchmark，得自建任务集与评分器 |

所以照抄 25 个阶段会导致 10–13（代码生成／实验运行／迭代精修代码）空转。下面只搬迁结构与纪律，改写执行方式。

## 三、改写：五个阶段的执行方式要换

| 原阶段 | 改写为 | 具体 |
|---|---|---|
| 10 CODE_GENERATION | 评测 harness 与评分器 | 不是算法实现，是：任务集 + 触发检测（技能是否被加载）+ 指标计算脚本 + 标注工具。**所有数字必须由脚本从磁盘实测**（已有先例：自述 161 行 vs 实测 212 行） |

| 22 EXPORT_PUBLISH | ACL 模板（LaTeX） | 8 页正文 + 强制 Limitations 节；不是 NeurIPS 9 页 |

## 四、五条红线照抄（这是那份提示词最值钱的部分）

1. **反幻觉**：禁止 `random.uniform()` 式编数据 → 我们的等价禁令：**禁止手写/估算实验结果数字**，一律脚本产出。
2. **方法—证据一致性逐行比对**：论文声称跑了几次、用了什么统计检验，必须与 log 逐行对得上；对不上判 CRITICAL FABRICATION，退回实验阶段。
3. **强制消融**：任何被称为"有效组件"的东西，必须报告移除后的对比。我们的消融清单：删负边栏 / 删假设表 / 删汇合层 / 只留输出格式。
4. **强基线**：基线必须同等用心调优。本领域基线应包含：自由推理、CoT、plan-and-solve、ToT（有结构但无账本——这是我们最关键的对照）。
5. **Limitations 必须诚实**：已知最大短板是**命中率 6/8 且漏掉的正是真实根因**（受限令牌／低完整性级别未被 forest 列出），这条不能藏。

## 五、它缺、我们必须自己补的三项

1. **标注者一致性**：那份提示词没有 IRR（Krippendorff's α / Cohen's κ）。人工评测没有一致性系数，结论不可信。
2. **触发率作为因变量**：本方法的前置条件是"技能被加载"。必须报告触发率（目前 3/3，n 太小），否则无法区分"方法好"与"根本没生效"。
3. **成本外显**：结构化必然更贵（字符数已实测：13013 / 10648 / 8569）。论文必须给"每个正确项成本"，否则审稿人一句"只是更长"就否掉了。
