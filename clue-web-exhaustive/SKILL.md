# 🕸️ 网状线索关联穷举法

用于探索未知、发现关联、创新组合。产物是**一张穷举表**，不是一段论述。

## 流程

拆解线索 → 建立关联（物理距离 + 关联度） → 构建线索网 → 穷举遍历。

## 产物：穷举表

固定列为：**线索 / 假设 / 证据 / 可能性 / 结论**。

- 每行必须标状态：`保留` / `排除` / `待验证`。
- 遍历完立即收敛，不把表留在发散状态。
- 「可能性」给相对量级（高/中/低 或百分比），不给模糊形容词。

## 风险与对策

**易淹没在细节** → 穷举表每行标「保留/排除/待验证」，遍历完立即收敛。

## 与其他模式的关系

- 模式优先级：穷举优先于质点代入法。先穷尽路径，再建模收敛。
- 不确定该用哪个模式时，默认用本模式。
- 复杂创造性问题：林状回溯 → 穷举 → 质点代入法 联用。

## 输出骨架

```
[🕸️] [选择理由]
| 线索 | 假设 | 证据 | 可能性 | 结论(保留/排除/待验证) |
收敛：<保留项排序 + 推荐>
待验证：<需要什么证据才能定案>
```
