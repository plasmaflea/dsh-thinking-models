# 🕸️ 网状线索关联穷举法

**简称**：网状图（产物）／穷举法（方法）。

## 这张图是什么

一张带权关联图。它填的是**横向关系**：谁和谁近、谁和谁相关、谁和谁能组合、谁和谁无关。

产物不是一段论述，是**一张穷举表**——关联图的矩阵形式，每行一条候选关系。

## 关系语法

只允许两种边：

- **关联边** `A — B`，带权：权重来自**物理距离**（越近越强）与**关联度**（同源、共现、因果邻近）。两种度量冲突时必须说明取哪个、为什么。
- **无关边** `A ⊥ B`：权重低于阈值即可排除，但要写下阈值。

不允许「可能相关」这种悬空边——悬空就标 `待验证`，并写明缺什么证据。

## 四种动作

1. **切出实体**——拆解线索，先求全，不求准。颗粒度不齐是常态，允许后续合并。
2. **定语法**——给每条边估权重；估不出就标 `待验证`，不许给模糊形容词。
3. **遍历完整**——每条线索都要与其他线索建立或否掉一条关系。只走「看起来相关」的边就是漏。
4. **负边也是结论**——排除项必须留档，否则无法证明你想过。

## 产物：穷举表

固定列：**线索 / 假设 / 证据 / 可能性 / 结论**。

- 每行必须标状态：`保留` / `排除` / `待验证`
- 「可能性」给相对量级（高／中／低 或百分比），不给"可能""也许"
- 遍历完立即收敛，不把表留在发散状态

## 风险与对策（降维损失的账本）

1. **淹没在细节** → 每行标状态，遍历完立即收敛。
2. **颗粒度不齐** → 先粗后细，粗层定态后再下钻，禁止同一张表混两种颗粒度。
3. **假完备** → 表满不等于全覆盖。结尾必须自问："有没有哪类线索我根本没列成行？"
4. **权重不可比** → 不同线索的权重口径要统一，否则排序无意义。

## 与其他两张图的关系

- 优先级：穷举优先于代入。路径没穷尽之前不要急着建模。
- 不确定用哪个模式时，默认用本模式（盲区最小、代价最低）。
- 复杂创造性问题：林状图 → 网状图 → 公式图 联用。
