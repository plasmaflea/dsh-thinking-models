## 条目必备字段（新增一类关系时必须写全）

**类型名 / 判定（怎么观测） / 强度上限 / 典型步数 / 反例 / 核查日期**。
缺「判定」＝这条路只说「近」不说「怎么看出来」，等于形容词，不算常量。

## 候选（v2 候选，尚未核查，用前须先核对）

- **跨域阈值**：软件／科研／商业是否各有一套阈值——目前只有「同题单尺」一条规则，没有按域细化。
- **支持边独立刻度**：证据强度（直接观察／文档／传闻）是否该有独立于关联边的分档。
- **时间衰减**：关系随时间变旧（三年前的共现算不算共现）——目前只作定性提醒，未入表。

## 本表的边界（不做什么）

- 只给「近不近」，不给「对不对」：方向与因果关系由林状图给，量级由结构图给。
- 不给概率：权重是**序数**，只能排序，不求和、不归一化成百分比。
- 不跨题比较：换题即换空间，旧权重一律作废。
