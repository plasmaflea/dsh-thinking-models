# 校准记录（`relation-table` 的实测附录）

> 类型表是**先验**；本文件收**实测**。顺序不能颠倒：先生出边，再记录「这次哪两条边排不出先后、最后凭什么排的」。
> 一条记录 = 一次冲突裁决。没有冲突的题不记（那是正常使用，不是校准）。

**记录版本**：v1 · **核查**：2026-10-19

---

## 1. 记录模板

```
### <日期> · <题名>
- 冲突：<边 A> vs <边 B>（两条都命中同一秩，且都影响结论）
- 各自判定：A 属第 <n> 类，<k> 步；B 属第 <n'> 类，<k'> 步
- 裁决：<最后怎么排> · 依据：<可观测的那一条，不是感觉>
- 结论是否因此改变：<是／否>
- 可迁移性：<这道题的口径能不能带走；多数情况是「不能」>
```

## 2. 已收录实例

### 2026-10-18 · 博客增长（`dsh-thinking-models/docs/benchmark/after/web.md`）

- **口径**：`W = S × F`
  - `S` = 传导强度（该路径对「在不增加写作量的前提下提升访问或收入」的因果传导强度，0–1）
  - `F` = 可行度（在「单人、零预算、800 访问基数」约束下真能执行的程度，0–1）
  - 分级阈值：`W ≥ 0.50` 首选；`0.30–0.49` 次选；`0.15–0.29` 降权；`< 0.15` 判无关边
- **为什么收录**：这是**支持边**的完整实例——它证明了「要给数字，就必须同时给出公式、阈值、分级」。缺任一项，数字不可复核。
- **不可迁移**：`S`、`F` 的具体取值属于那道题（单人、零预算、800 基数）；换题必须重估。**公式形式**可迁移，**数值**不可迁移。
- **一个限制**：`S × F` 把两个量纲不同的量相乘，是工程妥协，不是物理量。它只保证同题内可排序；不许拿 `W=0.42` 去和另一道题的 `W=0.42` 比。

### 2026-10-19 · 关系表 v1 定稿（本文件同时是首次校准）

- **冲突**：`A — B 强耦合` 与 `A — C 强耦合` 并列，二者都指向同一处置动作，排不出先后。
- **裁决**：按**机制步数**分——`A—B` 隔 1 步（A 直接作用于 B 的落点），`A—C` 隔 2 步（A 先改变入口，入口再改变 C 的量），故 B 在前。
- **结论是否改变**：否（两条都在保留区）；但边表因此多写了「步数」一列，后续可复核。
- **可迁移性**：「同秩看步数」可作为默认裁决顺序；「同秩同步数」才需要回到证据。

## 4. 归并规则

- 记录只增不改（历史裁决要有痕迹）；改判形如「2026-11-02 复核：原裁决 X，改为 Y，理由是 Z」。
- **季度归并**：积到 3 条同类冲突，才考虑动 `relations.md`；不足 3 条一律留在这里。
- 归并产物 = `relations.md` 升 `v(N+1)` + `CHANGELOG.md` 写理由。**不许把单条记录直接升格成类型。**
