# 🕸️ 网状线索关联穷举法

**简称**：网状图（产物）／穷举法（方法）
**技能 id**：`web-association-exhaustive`＝网·关联·穷举，与全称的三段结构一一对应

## 这张图是什么

一张带权关联图。它填的是**横向关系**：谁和谁近、谁和谁相关、谁和谁能组合、谁和谁无关。

产物不是一段论述，是**一张穷举表**——关联图的矩阵形式，每行一条候选关系。

## 关系语法

只允许两种边：

- **关联边** `A — B`，带权：权重来自**物理距离**（越近越强）与**关联度**（同源、共现、因果邻近）。两种度量冲突时必须说明取哪个、为什么。
- **无关边** `A ⊥ B`：权重低于阈值即可排除，但要写下阈值。

不允许「可能相关」这种悬空边——悬空就标 `待验证`，并写明缺什么证据。

### 2.1 权重是一个刻度，不是一堆数字

先分清两种边——它们的量纲、方向、用途都不同，共用一个「权重」即不可审计：

| | 关联边（线索—线索） | 支持边（线索／证据 → 假设） |
|---|---|---|
| 方向 | 无向、对称 | 有向 |
| 语义 | 关联度：同源／共现／因果邻近 | 可能性：该证据对该假设的支持度 |
| 用途 | 建网：生成假设、发现缺口 | 收敛：排序保留项 |
| 落点 | 本节 | 穷举表「可能性」列 |

**权重 = 关系类型（强度上限）× 机制步数（衰减）**。

- **关系类型**给上限：回答「这两个东西是用哪一类关系连起来的」。
- **机制步数**给衰减：1 步＝同一机制内直接作用；2 步＝中间隔一个能点名的量；≥3 步＝说不出中间那一步（说不出即 ≥3 步）。这让「远近」可被追问、可被复核，而不是感觉像。

| # | 关系类型 | 判定（怎么观测） | 强度上限 |
|---|---|---|---|
| 1 | 同一机制的直接因果 | 说得出「A 直接作用于 B」的机制 | 强·1 步 |
| 2 | 同一对象的不同侧面（同源） | 同一实体／同一日志／同一事务 ID | 强·1 步 |
| 3 | 同一恒等式的因子 | 能写成 `A = f(B, …)` | 强·1 步 |
| 4 | 必经时序的相邻步 | 生命周期或流程里紧邻 | 强·1 步 |
| 5 | 共现 | 同一时间窗或空间窗重叠 | 中·2 步 |
| 6 | 同一父类的兄弟 | 同一分类树同一层 | 中·2 步 |
| 7 | 同一职责主体／上下游 | 组织或调用链相邻 | 中·2 步 |
| 8 | 仅同类／同域 | 说不出机制，只是「都算软件问题」 | 弱 → 贴近阈值 |
| 9 | 无路径 | 说不出中间步 | 无关（写进无关边） |

**两条硬规则**：

- **同题单尺，跨题不比较**。口径统一只在同一道题内部有效；换题即换空间，旧权重一律作废。跨题比较是没有刻度的数字游戏。
- **不相干必须写阈值**，阈值以下进无关边；无关边也要留档（负边也是结论）。

**权重只做两件事，不做第三件**：

- ✅ 排序（哪个先验）＋ 定位（枢纽／断口）。**孤立点要单独看一眼**——零度或低度的线索，多半不是不重要，是边没想完（这是「假完备」的度量版）。
- ❌ **不许把权重当概率**：不求和、不归一化成「可能性 72%」。权重是序数，只能排序；给百分比就是假精度。

**估不出就标 `待验证`**（不写「可能」「也许」），并写明缺什么证据——这是「四种动作」第 2 条的执行细则。

**交付**：穷举表旁附本次边表（强／中／弱 ＋ 阈值 ＋ 用了哪几类关系）。没有这张边表，权重就是不可复核的形容词。

## 四种动作

1. **切出实体**——拆解线索，先求全，不求准。颗粒度不齐是常态，允许后续合并。
2. **定语法**——给每条边估权重；估不出就标 `待验证`，不许给模糊形容词。
3. **遍历完整**——每条线索都要与其他线索建立或否掉一条关系。只走「看起来相关」的边就是漏。
4. **负边也是结论**——排除项必须留档，否则无法证明你想过。

## 立场：并列全列，不锁一个

本模式的产物在**事实层**（有哪些可能），故天然容纳多立场——这是它与另两图规定**相反**的地方：🌳 锁一个、📐 锁一个并对齐执行者、🕸️ **全列**。规定不可互换，用错必漏。

- 穷举表每行必须标**持有者**（谁的视角／谁的利益）。
- **单立场穷举必漏**：站在一方视角，「还有什么没考虑到」恰好答不出来。
- **客观＝立场参数化后逐点求解**：不是"不带立场"，是把 `G` 当参数扫一遍，每个解标持有者。
- 换 `G` 才会变的部分（好不好／该不该）本模式**只登记、不裁决**，交 🌳 或 📐。

## 产物：穷举表

固定列：**线索 / 假设 / 证据 / 可能性 / 结论 / 持有者**。

- 每行必须标状态：`保留` / `排除` / `待验证`
- 「可能性」给相对量级（高／中／低 或百分比），不给"可能""也许"
- 遍历完立即收敛，不把表留在发散状态

## 风险与对策（降维损失的账本）

1. **淹没在细节** → 每行标状态，遍历完立即收敛。
2. **颗粒度不齐** → 先粗后细，粗层定态后再下钻，禁止同一张表混两种颗粒度。
3. **假完备** → 表满不等于全覆盖。结尾必须自问："有没有哪类线索我根本没列成行？"
4. **权重不可比** → 见 §2.1：同题单尺、跨题不比较；关联边与支持边分栏，两种边不共用一个刻度。

## 与其他两张图的关系

- 优先级：穷举优先于代入。路径没穷尽之前不要急着建模。
- 不确定用哪个模式时，默认用本模式（盲区最小、代价最低）。
- 复杂创造性问题：林状图 → 网状图 → 结构图 联用。
