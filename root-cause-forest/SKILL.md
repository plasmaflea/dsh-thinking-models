# 🌳 林状分层分类回溯法

用于定位根源、故障排查。产物是一棵**关系林（多根森林）**，不是一个线性答案。

## 流程

分层分类 → 按分类维度将问题**分裂为独立分支（每维一棵子树）** → 沿各子类链**并行回溯**寻根 → 构建**关系林（多根森林）** → 在**汇合层**合并 → 从根解决。

## 林状图定义

一个根问题按正交分类维度生成多棵独立子树（如"为什么要做"→动机链、"为什么能做"→能力链），每棵子树内部独立回溯，回溯到根后在汇合层合并。结构约束（无环、每节点完整分叉到所有维度）替代靠自律的维度守恒。

## 回溯根源：三层缺一不可

回溯根源 = 「问题产生的背景或现象」+「提问者想解决自己的什么现象」+「问题本身的根源」。

其他两层可以在逻辑通顺的情况下被其中一层覆盖掉或包含掉，从而获得真正的"根源"。多维度时各自独立回溯到根，再由汇合层合并。

## 风险与对策

1. **易忽略旁支路径** → 回溯前先枚举所有父类分支，再逐个剪枝，最后报告被排除的分支。
2. **单根树易跨维度跳跃** → 用林状图的独立子树物理隔离不同维度。
3. **分支爆炸** → 严格按照因果链来进行分类，不随意扩展。

## 分类与分层的取法

- 社会学问题中，先按阶级/地位/身份/性别等把所有涉及到的人分类，再对事情本身进行分类。
- 分层时按因-果联系分层，按必要/充分条件分层，按前置/后续关系分层。

## 输出骨架

```
[🌳] [选择理由]
维度一：<子树回溯链> → 根
维度二：<子树回溯链> → 根
汇合层：<多根合并>
被排除分支：<清单 + 剪枝理由>
结论：<从根解决的动作>
```
