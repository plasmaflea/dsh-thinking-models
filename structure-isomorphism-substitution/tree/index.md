# 结构模式库（索引）

**树版本**：v1 · **核查**：2026-10-19
**用途**：代入法的第一个动作不是「挑一个公式」，而是把待解问题归到下面某个**结构模式**上。模式给出「这一类的典型处置动作」与「越界后会退化成什么」，公式只是模式的一个实例。

## 模式表

| id | 模式 | 边型 | 一句话判据 | 越界后退化成 |
|---|---|---|---|---|
| `multiplicative-rate` | 乘性速率分解 | `总量 = 因子₁ × 因子₂ × …` | 能把总量拆成互相独立、可连乘的几个因子 | 因子相关 → 条件函数；出现饱和 → `saturation` |
| `conservation` | 守恒/账本 | `Δ存量 = 流入 − 流出` | 系统有清晰边界，进出可记账 | 存在不记账的旁路 → 先补账，否则不成立 |
| `saturation` | 饱和/非线性 | `延迟 ∝ S/(1−ρ)` | 有明确的利用率 ρ，且 ρ 接近 1 时成本非线性上升 | 到达突发或有限队列 → 只给量级；ρ≥1 → 不收敛，不适用 |
| `power-scale` | 幂律与规模效应 | `Y = k·n^b` | 规模 n 变化时单位成本随 n 改变 | 机制切换（沟通拓扑变了）→ 分段或换模式 |
| `additive-budget` | 加性预算分解 | `Σhᵢ ≤ B` | 串联路径，总预算被各段消耗 | 有并行/重试放大 → 改 max 合成或乘性叠加 |
| `queue-capacity` | 排队-容量 | `L = λW`；`吞吐 = min(λ, C/S)` | 有排队、有并发上限、有服务时间 | 有超时丢弃（守恒破裂）→ 只给上界 |
